# 共享普通 BUFF 规则（累计46项）

对应文件：beta-data/shared-buff-rules.mjs。当前共46项（前一批43项、本批追加3项），统一导出 SHARED_BUFF_RULES；每项是 (config, calculationInput) => 原生属性增量映射。此文件只定义规则，不负责切换内核、删除拦截、模拟战斗时间轴或自动推断来源命座。伊安珊、尼可E另在 recovered-character-rules.mjs 提供2项；普通独立倍率和直接星扩散倍率在 extension-buffs.mjs 定义，不计入本文件46项。全部入口合并后的当前目录覆盖为208/257，仍有49项命名BUFF未接入，详见 unified-buff-coverage.md。

## 输入、条件与单位

- 配置名称、默认值、上限取自 src/assets/_gen_buff.js；中文描述取自 src/i18n/generated/zh-cn.json。
- 攻击/生命/防御百分比以及增伤、减抗、减防、暴击等以小数表示；固定面板、精通、固定伤害以实际数值表示。
- 用户手动添加 BUFF 表示来源命座、解锁条件、施放/命中/治疗/反应触发、附近范围和有效时窗已经满足。覆盖率参数用于该效果对当前计算的适用比例，不自动模拟持续时间、层数流转或剩余生效次数。
- 场上限定效果在明确提供 recipient_on_field=false、input.team_effects.recipient_on_field=false 或 input.team_effects.on_field=false，或受益者角色参数 on_field=false 时失效。菲谢尔、爱诺、八重神子、温迪对自身的例外保留；仅靠缺少 on_field 字段不会擅自判定后台。
- 夏沃蕾天赋2只给火/雷角色加攻；莉奈娅二命只给水/岩角色加暴伤。优先使用明确的 recipient_element 或 character.element，否则使用从角色目录抄录的元素成员表。新增目录角色时应同步成员表。
- 砂糖魔导Q、阿贝多瑰银、布伦妮天赋1接受 recipient_is_magus=false 禁用魔导限定部分。当前没有从名称猜测的魔导身份表：未传该字段时，沿用原手动 BUFF 的“选择即声明适用”语义。自动组队接入方应提供受益资格，不应把规则存在等同于任意队伍自动触发。
- 黑蚀接受 recipient_is_wielder=true 排除装备者自身。杜林一命、洛恩二命、莫娜辉光根据受益者名称排除来源自身。莫娜辉光配置表示本次蒸发可消耗的层数，不模拟连续攻击的逐次消耗。
- 输入中的有限数值、层数/精炼整数与必要的布尔/元素列表由规则和共享注册表校验。
