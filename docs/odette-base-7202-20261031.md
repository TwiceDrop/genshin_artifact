# 奥黛塔基础乘区修复（2026-10-31）

来源：[Notion「奥黛塔基础乘区错误」](https://app.notion.com/p/40a9fe6be6ef80e99690fa9a8ca51fc8)，要求基础乘区上限为 14%。仅修改 V7.2.02。

## 原因与修复

`beta-data/preview-7201-facade.mjs` 对 `OdetteTalent1` 星超导模式另行覆盖为 `min(攻击力 × 0.000035, 0.07)`，导致米提亚／瓦列里扩展接口收到的基础加成减半。共享 `character-rule-book.mjs` 原先只声明星扩散分支，迫使适配层重复实现星超导。

将两个模式统一写入角色规则表：每 100 攻击力提升 0.7%，至多 14%；星超导写入 `StellarConductBaseBonus`，星扩散写入 `StellarSwirlBaseBonus`，无辉映时均不生效。删除适配层错误覆盖。手动 BUFF 与队友自动来源都经相同规则编译，DSL 与配装入口使用相同输入适配。

实际发布 WASM 的奥黛塔自身和旧内核队友原本已按 14% 计算；TeamDPS 奥黛塔模块也已正确，不改这些路径。冰旅行者的独立 7% 规则不属于本问题，保留。瓦列里目前没有星超导直伤技能，本次验证其 BUFF 编译槽位，未将其普通伤害变成星超导。米提亚／瓦列里未注册 TeamDPS 动作，故本次不改变 TeamDPS 规则版本或已有轴数据。

## 定向验证

所有输入均为合成数据，通过 `beta-tools/runtime-7106.mjs` 加载本版实际 WASM，不以 Rust 源码或 CPU/GPU 相等替代数值预期。

1. 独立倍率预期：1000／2000／3000 攻击力分别为 7%／14%／14%；两种辉映槽位、无辉映、锁定与禁用状态。米提亚技能直接用 403.2% 精通倍率、独立基础乘区／精通反应增伤／抗性／双暴公式核对。
2. 队友自动来源、DSL 与配装：合成奥黛塔提供满额加成，两个候选装备分别核对绝对伤害，再检查实际 Naive 配装结果；输入保持不变。
3. 原内核回归：奥黛塔自身与七七接收外部 BUFF 仍为 14%。
4. TeamDPS：仅执行 `team3-numeric.test.mjs` 的独立星超导数值用例，确认原正确路径不变。
5. `npm run build:local` 与 `npm run build:mobile` 均成功，输出 `dist`／`dist-mobile`；CSS 顺序、体积和 Browserslist 警告保留在 `build-local.log`／`build-mobile.log`，未改构建规则消除警告。

前三项位于 `tests/odette-base-7202.test.mjs`，修复前 2 失败／1 通过，修复后 3 通过；第四项 1 通过。证据保存在 `.build-target/odette-base-7202-20261031/`：`before.json`、`before-test.log`、`final-test.log`、`team-oracle.log`。中间 `after-test.log` 保留了测试预期漏计米提亚自身祝礼随精通增长的失败；根据已存在的独立角色规则和实际原生明细修正测试预期后通过，业务规则未因此放宽。
