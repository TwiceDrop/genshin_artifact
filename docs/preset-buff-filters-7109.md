# 7.1.09 预设菜单与角色 BUFF 元素筛选

日期：2026-10-06。编号 3 已完成源码实现；仅修改源码和记录，未构建或发布。

## 已实现

- 计算器现有预设按钮的下拉菜单加入元素筛选和排序选择，保留主按钮保存、另存为预设及应用预设。
- 默认按最近更新时间从新到旧排列；可切换元素属性排序，元素顺序沿用角色选择器，同元素内按最近更新时间排列。元素筛选与排序可组合使用。
- 当前 Pinia 预设入口 addOrOverwrite 在保存／覆盖时写入 updatedAt；账号持久化沿用既有完整预设条目。初始化保留已有更新时间。旧预设没有可恢复的历史时间，不虚构日期；在最近更新顺序中置于有时间记录的预设之后，彼此保留原有顺序。
- 在原“选择 BUFF”弹窗的“角色引发的 BUFF”页签加入全部元素及七元素筛选；UID 入口保留在前，其他 BUFF 页签及筛选逻辑未修改，按来源角色的元数据分类；角色选项、列表和现有搜索共同生效。切换元素清除此前聚焦角色与展开状态，保留命座、天赋、手动参数和已添加 BUFF。
- 旅行者通用和未分类来源没有唯一元素，仅在全部元素下显示；已有具体元素的旅行者按其角色元数据筛选。
- 没有新增帮助说明或小字，没有修改计算规则、账号、原存档或 README。
