# 莫娜占卜铺 7.2.04 更新说明

- **新增动态圣遗物评分**：根据当前技能或 DSL 伤害目标评分，可查看单件替换提升、参照配装和评分依据；保留喵喵评分，支持自由切换。
- **完善评分计算**：支持进度显示、取消和结果缓存，处理导入词条的浮点精度与四舍五入问题。
- **修复圣遗物组过滤**：按组的来源角色判断，避免其他角色的装备因出现在当前已选栏中而被错误放行。
- **新增“清空已选”**：一键卸下当前五件圣遗物，不删除仓库装备、预设或保存组。
- **新增外观切换**：支持浅色、深色和跟随系统，自动记住选择，并适配页面、弹窗及图表配色。
- **修复茜特菈莉二命增益**：补上队友的 250 点元素精通，按覆盖率生效，正确计入伤害、DSL、配装与词条收益计算。
- **新增匿名使用统计**：了解功能和角色的使用情况，不包含 UID、圣遗物或计算配置；首次启动时告知，可随时在设置中关闭。

提供 Windows EXE 安装包、ZIP 便携包，以及 Element Plus 和新 UI 测试版两种 Android APK。Windows 升级前退出旧程序；Android 使用对应界面的 APK 覆盖安装。
