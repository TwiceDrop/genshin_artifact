# 沃雅妮莎立绘与角色、武器图片排查记录

排查日期：2026-10-01。整理日期：2026-10-04。版本：7.1.08beta。

沃雅妮莎立绘、漩流颂歌图片及关联图标已在源码中修复。资源目录核对未发现其他缺失引用；当前网页 tray-repair1 已包含图片修复，Android android-export-repair1 尚未包含后续图片修改。

## 故障原因与修复

沃雅妮莎已有真实头像，但角色目录的 `splash` 字段仍指向水滴占位图 `/beta/vodyanitsa.svg`。导入角色列表优先使用这个字段，因此显示了占位图。计算页还通过专门条件隐藏了该角色的立绘。

| 位置 | 原问题 | 修复 |
| --- | --- | --- |
| 角色目录 `src/assets/_gen_character.js` | 沃雅妮莎立绘引用水滴占位图 | 改为本地真实立绘 `/characters/vodyanitsa-splash.png` |
| 武器目录 `src/assets/_gen_weapon.js` | 漩流颂歌引用同一水滴占位图 | 改为 `/weapons/hymn-of-the-maelstrom.png` |
| BUFF 与配装目标目录 | 六个角色 BUFF、一个专武 BUFF、默认配装目标仍使用占位图 | 角色效果与配装目标使用已有真实头像；专武效果使用真实武器图 |
| 计算页 `NewArtifactPlanPage.vue` | 专门排除沃雅妮莎立绘 | 移除该排除条件，沿用普通图片显示条件 |

新增图片保留下载的原始 PNG 字节，没有新增图片回退逻辑或界面说明。
