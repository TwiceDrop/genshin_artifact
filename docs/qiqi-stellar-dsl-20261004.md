# 七七六命定额接入奥黛塔／冰旅行者 DSL

日期：2026-10-04。版本：7.1.08beta。当前源码修复已完成；尚未打包进网页或 Android。

## 原因与修改

七七六命按来源攻击力的 600% 提供定额。共用支援规则已有该数值，单次接口已有结算；DSL 适配只为瑞希／桑多涅补入定额，对奥黛塔／冰旅行者直接抛出“不支持”错误。

业务修改仅在 `beta-data/stellar-support-facade.mjs`：沿用现有 DSL token 与伤害绑定处理，把定额附加到以下实际直接星扩散引用。普通伤害引用不改，原有其他限制保留。

| 角色 | 接入的直接星扩散 DSL 技能 |
| --- | --- |
| 奥黛塔 | `CodaStellarSwirl`、`PlumeStellarSwirl`、`WingStellarSwirl`、`C1StellarSwirl`、`C4StellarSwirl` |
| 空·冰 | `StellarSwirlBurst`、`ChargedIceCondensation1`、`ChargedIceCondensation2` |

定额在技能基础、精通及基础增伤之后，按现有内核的抗性、擢升和双暴结算；通用 `StellarSwirlDamageMultiplier` 只改变本体，不改变定额。DSL 内的暴击／期望比值随候选装备重算。

奥黛塔“赤忱者的悲歌”按候选攻击力重算，避免把当前装备的天赋乘区固定到所有候选。读取共用星扩散乘区时使用中性的冰伤参考，避免把冰旅行者爆发专属“寒辉”加成混入定额归一化，也支持 Playground 默认技能 index 0 的输入。

没有新增界面文案、额外校验、吞错、兼容回退或一次性抽象；没有修改原始内核、桥接、库存推荐、账号与预设。

## 五项针对性验证

第一项为故障复现；其余四项为 `tests/qiqi-stellar-dsl-7108.test.mjs` 的自动回归。均使用合成数据。

| 项目 | 实际结果 |
| --- | --- |
| 1 故障复现 | 修复前，`Odette.CodaStellarSwirl` 与 `AetherCryo.ChargedIceCondensation1` 携带七七六命均被 DSL 分支明确拒绝 |
| 2 DSL 数值与作用域 | 奥黛塔五条、冰旅行者三条受影响技能的期望／暴击／非暴击引用与单次接口一致；混合普通普攻的表达式也一致，普通段未增加七七定额 |
| 3 候选实际重算 | 两角色各两套候选，改变攻击、精通及双暴；每套优化评分与对应单次伤害一致，最优值为实际最大值；奥黛塔天赋随攻击变化并达到上限 |
| 4 倍率、词条收益与停用 | 通用倍率 0% 保留定额，150% 只放大本体；攻击词条收益与重新计算一致；停用七七 BUFF 后不加定额 |
| 5 当前源码 Worker | 独立编译当前真实优化 Worker、浏览器公共入口及其依赖；两角色的候选排序和数值与 Node 公共接口一致 |

最终命令：`node --test tests/qiqi-stellar-dsl-7108.test.mjs`。结果：4 项自动回归通过，0 失败。

首轮发现 Playground 默认技能不能直接提供星扩散参考；随后发现冰旅行者爆发“寒辉”只作用于本体，不能用于定额归一化。最终改用共用乘区参考并验证上述八条技能。合成装备曾误用 `Critical`，已修正为接口枚举 `CriticalRate`，没有将该测试输入错误当作应用故障。按已发现问题重跑失败项及受后续代码调整影响的四项，没有增加全量扫描。
