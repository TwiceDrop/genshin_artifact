# v7.1.07 正式版

将用户已实测正常的 7.1.07alpha2 转为正式版。保留全部功能及 Debug 模式，仅更新版本名称、Android 版本号和发布说明。

- 修复单人配装计算线程的打包入口，避免点击“开始计算”后发生线程启动语法错误。
- 保留 Debug 开关、具体错误信息和本地 JSON 调试包导出。
- 包含此前完成的角色 BUFF、星/月反应计算适配及单次手填面板。
- 既有适配限制和近似标记保持不变；不宣称任意旧角色、全部武器覆盖率或理论排行均已完整支持。

## 下载与启动

- genshin_artifact_V7.1.07_web.zip：解压，关闭旧版本服务，运行“启动7.1.07.bat”。需要 Node.js 20 或更新版本。沿用原浏览器访问 http://127.0.0.1:4183/#/calculate ，必要时 Ctrl+F5 刷新。
- genshin_artifact_V7.1.07_android.apk：Android 正式签名包，沿用旧版应用ID及签名。
- genshin_artifact_V7.1.07_source.zip：源码，不包含账号数据、签名密钥或用户调试包。
- SHA256SUMS.txt：发布文件校验值。

## Debug 使用

“开始计算”下方开启 Debug；若报错，点击“导出调试包”。刷新或离开页面前先导出。调试包只在本地保存，不自动上传，包含当前计算参数、候选圣遗物和错误事件。

用户已确认 alpha2 实测正常。本次按用户要求不运行额外测试；执行网页版与 Android 的正式构建。计算逻辑及双内核二进制与 alpha2 保持一致。
