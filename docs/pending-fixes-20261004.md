## 普通模式 C2 的暴伤作用域

旧内核把受益角色对应元素的普通暴伤读入星烁直伤双暴，导致沃雅妮莎普通模式 +50% 水冰暴伤串入奥黛塔星扩散。同一共享读取也会影响其星超导，已隔离复现。

共享规则继续给普通水冰伤害 +0.50 暴伤；仅在旧效果图、受益角色元素匹配时，将对应星扩散／星超导专属暴伤各减去 0.50，以抵消旧内核的串入。原生槽位分别为 224 和 217。补偿随原生候选图读取，不在页面当前装备上冻结最终伤害，也不影响星扩散模式原有 +0.60 专属暴伤。

旧图上下文只由既有旧角色分支提供。扩展内核不接收旧内核专属星超导槽，沃雅妮莎原生普通伤害继续获得应有暴伤。命座、前后台、普通模式和停用条件沿用共享规则。

修改：`beta-data/scoped-character-effect-rules.mjs`、`beta-data/facade.mjs`。原有支援测试把普通模式断言改为比较实际非暴击／暴击／期望伤害，而不是要求专属补偿槽为零。

## 漩流颂歌候选生命转攻击

旧适配先按当前装备算一次最终生命，再注入固定攻击百分比；优化输入未填写固定生命时直接拒绝。这既不能随候选装备重算，也无法产生实际生命词条收益。

现在沿用原生武器实现的公式，在旧内核增加 HP → ATKPercentage 的依赖边：

`min(max(最终生命 − 40000, 0), 20000) × (0.03 + 0.01 × 精炼) × 层数 × 强化系数 / 10000 × 基础攻击`

强化系数为普通 1、强化 1.75。原生 ATKPercentage 节点保存换算后的攻击数值；依赖来源为最终生命槽 26、基础攻击槽 27，写入槽 29。最终生命包括武器自身生命副词条、蜜酿生命加成、候选圣遗物和其他已启用生命效果。填写固定来源生命时仍使用明确填写的值；后台或零层不产生这项加攻。

`script/build-effect-bridge.py` 从保留的发布内核生成必要桥接。原生复杂图使用 f653，优化图使用 f433；函数闭包 ABI 沿用已核对的武器依赖边 t7／t9，提供同一公式的反向导数。没有替换 `mona_wasm_bg.wasm` 或重新编译 Rust 扩展。桥接生成器已移除原有哈希生成与校验。

修改：`beta-data/limited-weapon-facade.mjs`、`beta-data/legacy-effect-bridge.mjs`、`script/build-effect-bridge.py`、生成的 `mona_wasm/pkg/mona_effect_bridge.wasm`。

## 薇斯纳自定义 MONA-DSL

公共武器包装层的拒绝发生在已经存在的原生 DSL 路由之前。此次移除该拒绝，继续使用扩展已有的环境准备、BUFF 和武器转换。

辉映灵剑、爆发和六命灵剑使用已有 `direct_stellarswirl` 字段；普通普攻仍可在同一表达式中读取。没有修改 Rust DSL 对象或删除原有 normal 兼容访问语义。实际 DSL、候选优化和词条收益均已消费原生伤害，不仅验证入口不报错。

修改：`beta-data/limited-weapon-facade.mjs`。

## 显式星超导通用增伤与擢升

显式公式现在读取通用 `EnhanceStellarGlimmerReaction` 与 `ElevateStellarGlimmerReaction`。通用增伤与精通／专属增伤相加；通用擢升与显式擢升相加，作用于本体和定额合计后的最后乘区。

显式单次助手会先将这两项编译为星扩散属性别名。参数收集器依据既有 `source_buff` 还原它们的通用含义；不会将真正的星扩散专属增伤或擢升冒充星超导效果。

实际调用追踪：`direct-stellar-conduct.mjs` 由显式上下文和保留的底层单次助手调用；角色原生单次／单人优化不经过这份 JS 公式。桑多涅、奥黛塔的原生星超导此前已消费通用星烁增伤与擢升，本轮用实际单次、正确技能名的 DSL、候选优化确认，不能把显式漏算推成所有角色星超导失效。

修改：`beta-data/direct-stellar-conduct.mjs`、`beta-data/reaction-parameter-rules.mjs`。已删除的主C手填 UI 和独立反应入口没有恢复。
