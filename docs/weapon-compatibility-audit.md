这里的覆盖率是“平均属性”模型。通过平均属性再计算非线性伤害，不等于完整轮转逐次伤害的时间平均；本轮没有宣称增加轮转模拟。

补入的 BUFF 在传入原内核之前生成，故同一输入的面板、伤害、DSL、单人配装及属性收益共享该补偿。实际多人入口 optimize_team2 使用 single_interfaces 嵌套输入，已递归处理。也兼容遗留 characters/weapons/buffs 并列数组，但本地 Rust 的旧 optimize_team 已被注释，不把该分支说成当前活动入口。没有将角色实现切换成未验证的扩展角色。

静态评分 get_artifacts_rank_by_character(character, weapon, tf, artifacts) 使用位置参数，需要单独翻译第二个参数。该接口没有 BUFF 入参：若武器转换需要附加属性 BUFF，明确提示使用实际单人配装，不能把补偿丢掉后返回评分。

## 双状态计算依据

设战技状态覆盖率为 a，另一状态为 b，重叠比例为 o。真语秘匣：

- 精通 = 原精通数值 × (a + 0.5o)。
- 暴伤 = 原暴伤数值 × (b + 0.5o)。
- a 或 b 为 0 时 o=0；a=1 时 o=b；b=1 时 o=a。
- 两项都在 (0,1) 内时，只能得知 max(0,a+b-1) ≤ o ≤ min(a,b)，不能断言 o=min(a,b)。

因此 normalizeExpandedWeapon 对真语秘匣的不确定重叠也设防，避免扩展路径继续使用 min 猜测。纺夜天镜的效果元数据对未知重叠返回 null 和上下界，仍标记未建模，不把上界当作实际覆盖。

## 1～89 级审计

本地已有武器曲线、突破加值与每级数据；expanded_stats.rs 已能为扩展内核提供这些数据。障碍在原发布接口没有基础攻击力替换入口，而未校准的旧角色又不能安全切换到缺少其完整实现的扩展内核。ATKFixed 不能替代武器白值：它不会以相同方式影响攻击百分比和依赖基础攻击的天赋。因此本轮维持旧角色使用新增目录武器时的低等级限制，没有直接删 guard。
