# 莫娜占卜铺 7.2.01

本版包含四人固定轴DPS与联合配装，并保留单次伤害、单人配装优化及原有数据管理功能。

## 新增功能

- 米提亚、瓦列里与秘星典谕接入单次伤害、单人配装、DSL、词条收益及队友BUFF。
- 四人固定轴DPS：输入角色技能顺序，内部派生技能多段、召唤物、天赋、命座与增益；每次施放自动上场，后台事件保留实际前后台。
- 四人联合配装：同时分配20件不同ID圣遗物，支持CPU、GPU及混合计算，提供进度、取消、结果搭配与队伍伤害明细。
- 动作轴管理：先选四位角色，按角色选择中文技能；自动计算轴长、15秒保存草稿、手动保存提示、JSON导入导出及旧轴转换。
- 技能倍率预览：读取当前草稿，按角色汇总并展开每段时间、技能、前后台、基础倍率及角色修正。
- 动态生命与增益：队伍自身扣血、治疗、生命之契、气氛和相关装备效果随事件更新。
- 公共冰雷附着、ICD、超导／星超导及相关圣遗物、武器联动进入动作轴计算。

## 修复与完善

- 修复同刻动作、退场与增益刷新顺序、浮点轴尾、自动轴长与旧结果缓存失效问题。
- 修复跨账号自动保存竞态；任务参数与结果按账号、UID和轴分别保存。
- 补齐芙宁娜多段普攻／下落、满命水伤、荒芒切换与召唤物替换。
- 接入莫娜E／重击／Q与星异、可选破泡延迟；修复丝柯克七相资源自然消耗、裂隙吸收暂停与耗尽退场。
- 接入桑多涅、奥黛塔、阿罗夏、七七和八重神子动作规则，计入辅助角色自身伤害；神子独立樱时钟、附着、命座及星伤进入评分与预览。
- 修复叶洛亚低等级爆发索引与导入异常、米游社人工验证完成后同步、部分异常圣遗物重复导入及关联BUFF作用范围。
- 保留取消自动超时、阶段ETA、完整搭配排序／换装、CNB优先更新和两种Android界面。

## 使用范围

动作轴当前支持丝柯克、芙宁娜、爱可菲、沃雅妮莎、莫娜、桑多涅、奥黛塔、阿罗夏、七七、八重神子。米提亚与瓦列里本轮的角色适配属于单次／单人计算，尚未注册多人动作模块。

轴计算沿用初始满能量、无循环充能验证的理论口径；不计算敌人造成的伤害。未登记动作、完整水火草混合反应及丝柯克裂隙自动产出仍待扩展，桑多涅部分时序保留近似。示例轴不自动覆盖已有配置。

提供Windows x64安装器、ZIP便携包、原Element Plus APK及独立新UI测试APK。Android沿用原包名和升级签名；两种UI的数据分别保存。规则升级保留任务参数并使旧计算结果失效，请重新计算。
