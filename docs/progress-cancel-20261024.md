# 7.1.12 计算进度、取消与自动超时调整

日期：2026-10-24。用户明确要求本轮同时同步7.1.12和7.2.01EA。

## 实现

- 移除单人配装Worker原600000毫秒自动终止计时器；不改成更大的时限。保留初始化失败、内核异常及Debug真实错误。旧中英文提示中已删除自动超时表述。
- 进度窗新增“取消计算”。AbortSignal直接终止当前Worker并清理回调，不依赖忙碌线程处理取消消息；完成/失败也保留原线程释放。取消显示“计算已取消”，Debug状态与导出记录为cancelled，无失败错误，不应用部分结果；保留上次装备、结果及选中编号，不自动保存预设。离开页面或切换账号时释放当前任务。
- ETA使用已有原生观察回调的阶段掩码，将四件套、二加二、两件套、不限套装分别计速；阶段切换时清空旧样本。使用最近约8秒分组速度，至少3个完成分组和1秒样本才估算。尚有后续阶段时明确标为“本阶段预计剩余时间”，最后阶段才显示总剩余时间。纯枚举沿用单阶段。
- 页面时钟持续刷新已用时间；估计到期但搜索未结束时显示“估算中”，不把旧数值固定在1秒。阶段内分组成本仍不均匀，ETA为估计，不把分组百分比当耗时百分比。

## 范围与交付

本轮只改进度观察、任务生命周期、进度窗和两句旧提示，伤害公式/搜索算法/候选/目标/约束/原生计算及存档格式均未修改。7.1.12之前属性图优化保持；没有把它移植至EA，也没有覆盖EA的角色或联动实现。历史记录“产品600秒未改”是当时验证边界，当前自动时限已按本次授权删除。

继续使用原../launcher/启动7.1.12.exe；本轮未改EXE、版本、端口、README，未生成安装器/ZIP/APK或发布。新UI已构建网页，未声称Android实机验证。本轮未读取或复制真实账号导出，不操作用户存档。
