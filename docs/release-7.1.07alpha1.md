# v7.1.07alpha1 网页测试版

用于排查“开始计算”后的错误。按用户要求仅构建，不运行本测试版的自动测试、浏览器测试或手动测试。此前修复过程的检查结果不能当作alpha1已通过测试。

## 启动与收集报错

1. 关闭旧版服务窗口，在新目录双击“启动7.1.07alpha1.bat”。需要已安装Node.js（20或更新）。
2. 默认仍使用 http://127.0.0.1:4183/#/calculate 。沿用原浏览器和这个地址可继续使用该来源下的仓库数据。若端口占用，请先关闭旧服务；打开后确认浏览器页面标题版本为7.1.07alpha1，必要时Ctrl+F5刷新。
3. 在单角色计算页“开始计算”按钮下方，打开“Debug 模式”。保留会报错的角色、武器、BUFF、算法及套装限制，然后点“开始计算”。
4. 报错后点“导出调试包”，将生成的mona-debug-7.1.07alpha1-时间戳.json提供给后续排查。也可展开“查看调试阶段与错误详情”直接查看。
5. 调试记录仅保存在当前页面内存；请先导出，再刷新或离开页面。每次开始计算会替换上一次记录。

## 调试包包含什么

- 版本、时间、浏览器环境；角色、武器、BUFF、敌人和优化约束。
- 经过实际筛选、穿戴保护及等级限制之后的候选圣遗物完整数据；按部位、套装汇总的数量。
- 线程创建、内核就绪、参数发送、优化开始／结束、超时及异常阶段。
- JavaScript错误名、信息、堆栈、线程报错位置；启用Debug时，另外保留本次原生计算输出到console.error/warn的诊断（最多30条，每条最多8000字符）。
- 计算成功时的结果数量和前5组简表，便于区分“内核失败”与“应用结果时失败”。

不读取Cookie、登录凭据或整份浏览器存储。不自动上传调试包；开启Debug时也不上传这次计算的普通结果。记录可能含队友来源ID、角色配置和装备编号，分享前可先查看JSON。

## 本版代码变化

- 单人优化Worker现在返回具体错误，前端保留可展开详情；失败和超时会清理线程及计时器。
- 补上晨星与月的晓歌、天之美赐、影中沉凝的幻灭的扩展套装支持登记，使用内核里已有的效果实现。
- 直接星扩散读取攻击条件暴击率、风元素暴击率和风元素暴击伤害，补上影中沉凝的幻灭及珐露珊六命相关消费；不把普通增伤和定额自动赋予星伤。机制依据：[KQM星反应指南](https://keqingmains.com/misc/stellar-reaction-guide/)、[KQM圣遗物资料](https://library.keqingmains.com/equipment/artifacts)。
- 原发布内核保持不变，扩展WASM已重编译。多人星扩散近似、固定面板不能用于自动优化等限制保留。

用户已确认移除上述三套后仍报错，因此不能把支持名单遗漏认定为当前报错的完整根因。alpha1的目的就是收集实际故障现场，并非宣布问题全部解决。
