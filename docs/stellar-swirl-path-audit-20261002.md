# 旧内核角色自身星扩散来源排查

日期：2026-10-02。版本：当前 7.1.08beta 源码。目标是确认哪些角色凭自己的技能、天赋或命座直接造成星扩散伤害，并查清 `StellarSwirlDamageMultiplier` 的实际影响范围。

## 当前状态

后续已按用户授权修复 `StellarSwirlDamageMultiplier` 的四条旧路径接入，五项针对性核对通过，见[倍率修复记录](stellar-swirl-multiplier-20261002.md)。下面保留来源排查和修复前拒绝行为，便于追溯。

## 来源排查结论

原记录中的“旧角色”用词不准确，这里实际指仍走原发布 WASM 的角色路径。不能把它解释成所有老角色天赋或命座都缺少星扩散适配。

当前项目已确认四条旧内核路径能直接产生自身的 `direct_stellarswirl`：梦见月瑞希、奥黛塔、桑多涅、冰旅行者。它们的自身星扩散技能已有实际伤害结果；来源排查时尚未接入的是另行添加的通用 BUFF **“直接星扩散-造成原本伤害%”**，对应 `StellarSwirlDamageMultiplier`。本次传入 150% 时，四条公共接口均明确拒绝，并未静默漏乘。

来源排查阶段只修订记录；后续倍率修复阶段修改了共享桥接及适配代码，只重生成必要桥接，没有恢复独立反应入口或打包应用。

瑞希一命还包含对当次自然反应的 550% 来源精通加值，它与上述 400% 精通的额外直接攻击是两个效果；本次只列自身直接攻击，不恢复已删除的自然反应页面。瑞希六命是双暴强化，不增加第三个自身星扩散伤害段。

## 相关老角色为何不计为自身直接星扩散

核对了下列角色当前天赋与命座原始文本：

| 角色 | 实际相关效果 | 是否新增自身直接星扩散伤害段 |
| --- | --- | --- |
| 七七 | 天赋提供反应增伤；六命在其他当前场上角色直接造成星烁伤害时，按来源七七攻击添加定额，且明确排除七七本人 | 否；该定额附在受益角色已有伤害段上。寒病鬼差协同攻击仍为普通冰伤 |
| 迪奥娜 | 珍选秘藏在队伍触发相关反应后发射猫爪；六命提供星扩散增伤 | 否；协同猫爪没有“视为星扩散伤害”的转伤定义 |
| 万叶、砂糖 | 星扩散可触发原有元素增伤／精通共享 | 否 |
| 温迪 | 星扩散触发魔导天赋增伤及暴风之眼原伤害倍率强化 | 否；暴风之眼没有因此转为直接星扩散 |
| 早柚 | 星扩散触发治疗、四命能量回复 | 否 |
| 法尔伽 | 星扩散触发伤害强化层数、四命元素增伤 | 否 |
| 布伦妮 | 星扩散触发元素转换、攻击力提升及 150% 攻击的对应元素追击 | 否；追击定义为元素爆发伤害，没有星扩散转伤 |
| 丝柯克 | 星扩散进入虚境裂隙的触发列表 | 否 |

能自然触发星扩散、给星扩散增伤，或在星扩散后追加普通元素攻击，均不自动代表角色拥有自身直接星扩散。薇斯纳属于扩展内核，她的辉映灵剑和六命自身伤害走 `stellar_swirl`，不在这条“旧内核未接入”记录里。

## 修复前的独立倍率缺口

- `beta-data/buff-rule-schema.mjs:258` 定义通用输入，默认 100%。
- `beta-data/extension-buffs.mjs:25` 将其转换为 `StellarSwirlIndependentBaseMultiplier = p/100 - 1`。
- `beta-data/lunar-context-facade.mjs:19` 在调用旧内核前拒绝该 BUFF；仅扩展内核角色或保留的显式单次上下文有对应接入。当前的用户界面手填入口仍已删除。
- `beta-data/legacy-effect-slots.mjs` 没有已核对的 `StellarSwirlIndependentBaseMultiplier` 槽位；`legacy-effect-bridge.mjs` 也没有将该通用 BUFF 编译进这四条角色路径。
- 浏览器 `mona_wasm/pkg/index.js` 和 Node `beta-tools/runtime-7106.mjs` 都使用该公共包装，单次、优化和 DSL 等输入共用检查。本轮只实际调用单次接口，其他接口的拒绝机制按代码调用链确认。

因此原先“旧角色星扩散专属倍率并未全部接通”的笼统表述应改为：**旧内核的四条自身星扩散路径可以计算，但尚不能使用额外通用倍率输入。** 这不影响没有添加该 BUFF 时已有天赋／命座自身伤害的计算，也不证明七七等支援效果的其他已知缺项已解决。

若后续接入，独立倍率应作用于自身技能伤害本体，定额加值的作用位置另按现有规则保留；普通伤害、自然反应及星扩散增伤不能被同一参数一起缩放。现在没有为绕过报错而把它改成普通增伤或直接乘最终结果。
