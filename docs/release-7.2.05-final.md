# 莫娜占卜铺 7.2.05 更新说明

- **配装对比更直观。** 在角色卡上就能切换候选方案，逐件查看词条变化，对比换装前后的技能伤害，也能一键恢复原装备。
- **同一角色可保存多套配装。** 预设分为「游戏内」和「自定义」。配装结果可以另存为自定义预设，刷新 UID 后仍会保留。
- **Windows 新增四人轴编辑器。** 把技能拖到四条角色轨道上，按 0.1 秒微调，点选技能查看命中倍率，悬停查看 BUFF 生效时段。旧配装缺少圣遗物时也能继续优化。
- **圣遗物更好找。** 仓库改为分页卡片，可按套装和主词条筛选，点开即可编辑。喵喵评分现已支持米提亚。
- **桌面和手机界面焕新。** 新增星盘首页，手机配装页改为单列。首次使用可按引导导入 UID 或圣遗物文件。Windows 安装器支持简体中文和升级时选择目录。
- **计算修正。** 90 级讨龙英杰谭、铁影阔剑的生命副词条由 41.3% 修正为 35.2%。修复旅行者「真实之月」共鸣计算，以及丝柯克部分动作顺序下的爆发预览报错。

- **新增兹白月结晶四人轴。** 可导入兹白、哥伦比娅、莉奈娅和叶洛亚的队伍示例，查看角色直伤和月笼谐奏伤害。
- **桌面内容补丁。** 配置补丁服务后，桌面版会自动检查数据更新，验签通过的补丁在下次启动时生效。

**在线账号与同步**　已登录并绑定云档案后，软件每 60 秒检查一次同步。换设备前可以点「立即同步」。线上开放时间待确认。
