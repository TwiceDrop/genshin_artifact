# 莫娜占卜铺 7.2.06 更新说明

自 7.2.04 以来的累计更新，含 7.2.05 和 EA 版内容。

- **单人配装会自动设置套装效果。** 根据配装角色和已启用的队友 BUFF 判断层数、覆盖率和队友人数。例如，芙宁娜的 BUFF 可让逐影满层，饰金按不同队友的元素计数，宵宫的追忆和魈的辰砂自动开满。也可以切回手动调整。
- **补齐月反应加成。** 如雷四件套增加 20% 月感电伤害。乐园四件套的月绽放加成为 10%～20%，绽放、超绽放、烈绽放为 40%～80%。套装说明、单次伤害和配装计算已对齐。
- **新增兹白月结晶四人轴。** 可导入兹白、哥伦比娅、莉奈娅和叶洛亚的示例队伍，查看角色直伤和月笼谐奏。Windows 时间轴编辑器支持拖动技能、按 0.1 秒微调、查看命中倍率和 BUFF 时段。旧方案缺少圣遗物时也能继续优化。
- **配装和仓库更好用。** 在角色卡上切换方案，逐件对比词条和技能伤害，一键恢复原装备。同一角色可保存多套自定义预设，刷新 UID 后也会保留。圣遗物仓库支持分页、筛选和直接编辑，喵喵评分新增米提亚。
- **桌面和手机界面焕新。** 首页改为星盘布局，手机配装改为单列，首次使用可跟随引导导入 UID 或圣遗物。Windows 安装器支持简体中文，升级时可选择目录。
- **全账号备份与迁移。** 在「设置 → 导出数据」备份所有账号的历史详情、四人轴、个人任务、UID、圣遗物、角色预设和配装收藏。导入时每个账号都会另存为新账号。网页版迁移弹窗可直达设置。
- **账号与云同步。** 支持密码或邮箱验证码登录，可按数据类别选择同步。已绑定的云档案每 60 秒检查一次，换设备前可点「立即同步」，也可将历史修订恢复为新账号。
- **其他计算修复。** 修正旅行者「真实之月」共鸣、丝柯克部分动作顺序下的爆发预览，以及 90 级讨龙英杰谭和铁影阔剑的生命副词条（35.2%）。

**Windows Tauri 更新**　从 **7.2.05EA 升至 7.2.06** 时，请在 CNB 或 GitHub 手动下载一次文件名以 `_tauri_x64.exe` 结尾的程序，退出旧版后替换并打开。此后可在程序内确认更新，自动下载并重启。Windows ZIP 便携版继续通过原启动器更新。迁移通知仅在通过域名访问的托管网页版显示。桌面版还支持单独更新计算数据，已下载并通过签名校验的内容补丁会在下次启动时生效。

**Android 更新**　正式版和 mobiletest 的界面与功能相同，包名不同，可同时安装。升级时选择与已安装版本对应的 APK。
