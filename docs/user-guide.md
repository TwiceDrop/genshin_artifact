# 莫娜占卜铺玩家手册

新增玩家可见功能、调整导入方式、计算入口或备份流程时更新。

想知道「这套装备的大招能打多少」，打开首页的「计算器」；想从库存里找更好的五件，在同一个计算器选择优化目标。想给四个人分配互不冲突的圣遗物，并比较一套动作顺序下的全队伤害，进**多人优化**。桌面侧栏可以切换功能，手机底部可直达计算、圣遗物和角色，其余入口在「全部功能」里。

首次进入登录页时可点「以离线模式继续」。

下文按当前开发分支的界面名称指路。若使用 7.2.06.04 发布版，展柜导入在「UID 数据 / 手机互传」中，按钮叫「使用 Enka API 登录」；点开后同样是输入 UID，再点「导入展柜角色」。[7.2.06.04 发布说明](release-7.2.06.04-final.md)

## 第一步：准备角色与圣遗物

| 手头有什么 | 从哪里导入 | 导入后能用什么 |
| --- | --- | --- |
| 游戏 UID，且角色已放入公开展柜 | 「角色」`/uid-data` →「添加角色」→「UID 导入（Enka 展柜）」，输入 UID，点「导入展柜角色」 | 公开角色、武器和已穿戴的圣遗物。背包中的散件需要另行导入。 |
| 导出工具生成的圣遗物 JSON | 可以先从「导出工具」`/help/export-tools` 找到工具。打开「圣遗物」`/artifacts` →「导入」，窄屏在「更多」中选择，选好文件后确认 | GOOD（含 v3）可补入未穿戴装备；缺少 UID 的 GOOD 文件会询问归属。莫娜仓库 JSON 也从这里导入，确认前留意是否勾选删除本次未出现的装备。 |
| 带角色和武器的 GOOD v3、角色快照或 UID 数据包 | 「角色」→「添加角色」→「导入文件」，按提示确认目标 UID 和角色 | 可在对应 UID 下选择角色、查看穿戴或载入预设。遇到已有角色的替换提示，逐个确认要采用的新数据。 |
| 暂时没有导出文件 | 「角色」→「添加角色」→「手动添加角色」；已有米游社原神战绩分享图也可选「识图导入」 | 手动补齐或核对识别出的信息，再进计算器。 |

**米游社扫码**在 7.2.06.04 发布版暂时关闭。当前开发分支已有扫码按钮和处理流程，但不能据此判断发行版或某台设备能成功登录。只需展柜角色时可直接走 UID 导入，无需提供 Cookie。[当前版本状态](dev/current-state.md)

## 算一次伤害，再找一套配装

1. 打开计算器 `/calculate`，选择角色或载入自己的角色预设，核对等级、命座、天赋、武器等级与精炼，选好当前穿戴。先看关心的技能和反应对应的伤害行；暴击、非暴击和期望是三种不同口径。
2. 在 BUFF 区加入实际生效的队友效果，检查来源角色、层数及覆盖率。在敌人设置里填写等级和抗性。点开伤害明细，可逐项查看该段伤害的构成。
3. 要从仓库搜索时，先选**目标函数**，例如希望提高的某个技能期望。搜索按目标函数排名；只切换正在查看的伤害行，不会替你更改优化目标。在「计算设置」选套装、主词条和属性下限，核对「圣遗物设置 → 保护圣遗物」后点「开始计算」。
4. 切换结果方案，看面板、五件装备和技能伤害分别如何变化。词条收益用来判断当前配置再加暴击、精通等属性的价值；最优收益曲线可比较不同词条预算。满意的配置可存为角色预设，常用五件组合可存为套装。[词条收益、评分与穿戴保护详解](local-features.md)

## 多人优化与四人固定轴

首页「多人优化」`/team-optimization` 同时提供四人轴和联合配装。已有一套想验证的穿戴时，可以先算当前配装，再决定是否让程序重分库存。

1. 点「导入计算配置」选择动作轴 JSON，或在「管理计算配置」中新建动作轴。可从[兹白月结晶队示例](../examples/team-dps/zibai-lunar-crystallize.json)起步。自建时选四名受支持的角色，排好切人和技能顺序，再点「用于计算」。
2. 逐个点击队伍头像，载入该成员的角色预设或填写武器、命座和天赋；在各自的「配装设置」中限定候选装备。核对敌人参数。要点「计算当前配装」，四名成员都需有五件当前库存中能找到、且该轴支持其套装的圣遗物；可逐人载入带齐装备的预设。只有角色参数或穿戴不齐时，可继续下一步搜索。
3. 要重新分配库存，在「联合优化」选择总伤或总 DPS、结果套数及评估预算，点「开始计算」。同一件圣遗物不能同时分给两人。结果中可查看四人的穿戴、个人伤害占比、总伤与轴长。标有「有限预算结果」时，排名只覆盖本次已评估的搭配。

这里的 DPS 是这段固定轴的总伤除以轴长。计算假设初始满能，没有循环充能和敌人来伤；部分动作时序使用近似值。比较两个方案时使用相同轴、敌人参数和伤害口径。可选角色和反应范围见[当前版本状态](dev/current-state.md)。

## 整理仓库与回看结果

| 页面 | 适合做的事 |
| --- | --- |
| 角色 `/uid-data` | 按 UID 找到角色，管理该角色的多套预设。计算器里修改和保存的配装可与最近导入的游戏穿戴作对比。 |
| 圣遗物 `/artifacts` | 按部位、套装等条件筛选。打开一件查看详情、评分和适配角色，再决定是否锁定。GOOD 导入按 UID 和装备词条逐件匹配：再次导入可复用已有件，文件里两件完全相同的装备仍按两件计数。 |
| 圣遗物套装 `/artifacts-kumi` | 在收藏夹里保存和整理常用的五件组合。想保留武器、天赋和 BUFF 等完整计算条件时，保存角色预设。 |
| 历史记录 `/calculation-history` | 在「单次计算」和「多人配装计算」之间切换，按角色搜索并点开记录，回看当时的状态与详情。 |

## 本地账号、换设备与云同步

**切换本地账号。** 在「本地账户」`/account` 点账号卡片切换，或新增账号以分开管理库存和预设。导入前先核对当前本地账号和游戏 UID。

**完整搬家。** 在旧端从侧栏的「设置/导出」进入设置页（`/setup`），点「导出数据」，将备份文件带到新端，在同一页点「导入数据」。预览中核对账号、UID、圣遗物、四人轴和历史记录数量，再点「导入为新账号」。每个来源账号都另存一份。想一起迁移语言和外观，可在预览里勾选。把文件保存在自己控制的位置。

Windows 安装器和网页便携包使用默认浏览器，同一浏览器配置和访问地址可共用存储。更换浏览器、主机名或端口会看到另一份仓库。Tauri 独立窗口和 Android 应用也各有自己的存储，Android 正式版和 mobiletest 可以同时安装。跨这些环境迁移时使用完整备份。

**使用云档案。** 项目的公共账号服务仍待部署和实机验收。已有可用服务地址时，可从侧栏登录，或在「设置 → 账户管理与同步」进入 `/online-account` 保存服务地址。登录后选择同步内容，点「关联当前账号并自动同步」。启用后每 60 秒检查一次，换设备前可点「立即同步」并核对云端修订；另一端登录同一在线账号后选「下载为新本地账号」。没有可用服务时仍可离线计算，通过文件换机。

## 常见问题

**升级后仓库怎么空了？** 先确认「本地账户」是否选对。再用原来的启动器、浏览器配置、主机名和端口打开旧入口。找到数据后，从旧端导出全账号备份再导入新端。保留旧端数据直到确认迁移结果。

**找不到配装或伤害和预期不同？** 先确认每个部位有符合条件的候选，检查锁定、主词条和替换限制。伤害有偏差时，核对技能段、反应、暴击口径、敌人抗性和已启用的 BUFF。

**如何反馈计算异常？** 单人配装在「计算设置 → Debug 模式」开启记录，按原条件重算，再点「导出调试包」。出现计算错误弹窗时也可以直接导出错误报告。四人轴可在「联合优化」勾选「Debug」，重算后点「导出Debug」。反馈时写清版本、角色或队伍、操作步骤，以及预期和实际结果。调试文件可能含 UID、装备或预设，请先检查内容，只把必要材料私下交给维护者；不要公开发送 Cookie、登录凭据或全账号备份。
