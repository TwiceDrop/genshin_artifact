# 02: 计算器配色变量与抽屉外壳

**What to build:** 计算器内容区的浅色 / 深色配色变量，以及一个通用的编辑抽屉外壳，后面的任务都用它们。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

规格见 `../spec.md` 实现决定 1、5、8。

- [ ] 在计算器页定义 `--cx-*` 变量：内容区底色、卡片、两级色阶、文字、次要文字、强调色（金）及其上的文字；深色一套、浅色一套；变量名避开 `postcss-mona-colors.cjs` 的角色词
- [ ] 角色卡用的夜空色直接读外框的 `--sh-*`，不另定义
- [ ] 新建 `CalcDrawer.vue`：基于 `el-drawer`，桌面右侧 440px 宽、手机（≤820px 容器）底部全高；有标题和关闭按钮；Esc 关闭；打开时焦点进抽屉，关闭后回到触发按钮
- [ ] 抽屉在手机上不被底部导航遮住，底部留安全区
- [ ] 验证：临时挂一个空抽屉，桌面和手机宽度各开关一次（不提交临时代码）
