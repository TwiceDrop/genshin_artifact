# 04: 角色卡

**What to build:** 第一屏的夜空色角色卡：立绘、名字与元素、三颗胶囊、武器条、五个圣遗物槽位与总评分、八项关键面板。

**Blocked by:** 02

**Status:** ready-for-agent

规格见 `../spec.md` 解决方案 2、实现决定 3、4。

- [ ] `CharacterHeroCard.vue`，props 只收展示数据和事件，不直接调用 store
- [ ] 立绘按决定 4 推导，加载失败时显示角色头像；立绘右侧和底部渐隐到夜空色
- [ ] 名字左边是元素图标；胶囊：等级、命座、天赋三档（普攻 · 战技 · 爆发）
- [ ] 武器条：图标、名称、「Lv · 精炼」、效果第一句，右侧「更换 ›」
- [ ] 五个槽位：空槽显示部位图标和「+」，有圣遗物时显示该件图标、主词条和等级；旁边显示当前评分模式的总分和标签
- [ ] 右侧八项面板，暴击率、暴击伤害金色；底部「全部属性 · 收益曲线 ›」
- [ ] 每一块都是按钮，发出打开对应抽屉的事件（抽屉内容在 05 做，这里先接到现有弹窗或空抽屉）
- [ ] 验证：换角色、换武器、选一件圣遗物后卡片内容正确；面板八项与旧右侧面板数值一致
