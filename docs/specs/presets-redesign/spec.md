# 计算预设页视觉重做

Status: done

2026-11-15 开发者要求重做计算预设页。这一页的分类、搜索、编辑、导入规则和新增文案已在 `docs/specs/character-presets/spec.md` 与开发者确认过，本次只改视觉，交互规则和文案不动。视觉沿用圣遗物页和套装页。任务在 `issues/`。

## 给执行者

- 在本地分支 `ui-redesign` 上做，一次本地提交，不推送。
- 不改 `preset-workflow.mjs`、预设 store 和编辑弹窗里的逻辑；文案沿用 `character-presets/spec.md`「已确认：新增界面文案」。
- 不新增界面文字；卡片的「…」菜单用既有的「导出」「删除」。

## Solution

1. **页面**：内容区底色的圆角区域；顶部标题「计算预设」、「导入」「导出全部」、金色「新建自定义预设」。
2. **列表组件 `PresetBrowser`**：「游戏内 / 自定义」改成药丸形分段按钮；UID 选择和搜索在下一行。计算器的「导入角色预设」「应用圣遗物到预设」弹窗用同一组件，会一起变成新样式。
3. **预设卡片 `PresetItem`**：角色头像、预设名、角色名、武器（图标和名称）、计算目标（图标和名称）；右上角「…」菜单（导出、删除）。props 和事件不变。
4. **编辑弹窗 `PresetEditor`**：只套用 `--cx-*` 配色和金色主色，内容不动。

## Testing Decisions

- 浏览器实测：用合成预设，桌面和手机、浅色和深色；切换标签、搜索、打开编辑、导出 / 删除菜单；计算器的导入角色预设弹窗。

## Out of Scope

- 预设分类、刷新、应用结果等规则；编辑弹窗内部布局。
