## Problem Statement

- 每组套装的五件圣遗物是一排 200px 宽的旧卡片，放不下，每组下面都有横向滚动条。
- 组上没有汇总，看不出几件套。
- 重命名、删除是很小的图标；收藏夹的重命名、清空、删除和新建套装挤在一条工具栏里。
- 左栏收藏夹只是几行文字，看不出每个收藏夹里有几组。

## Solution

1. **左栏**：「＋ 新建收藏夹」和收藏夹列表，每项带组数，选中项高亮。
2. **右侧顶部**：收藏夹名和「N 组」、搜索框、「更多 ▾」（重命名、清空、删除收藏夹；默认收藏夹和游戏中导入只能清空）、金色「＋ 新建套装」。
3. **套装卡片**（宽屏两列）：组名、套装汇总（如「炽烈的炎之魔女 4 · 角斗士的终幕礼 1」）、五个部位格（图标、等级、主词条数值；空格显示部位图标和「+」）、右上角「…」菜单（重命名、删除）。点部位格打开现有的选圣遗物弹窗；有圣遗物的格子悬停或聚焦时显示「×」，点了从这组移除。
4. **手机**：收藏夹变成顶部横向滑动的标签，新建收藏夹进「更多」；卡片单列。

## Implementation Decisions

- `ArtifactIcon.vue` 第二个页面用到，移到 `src/components/display/ArtifactIcon.vue`，圣遗物页改引用。
- 组数取 `kumiStore.kumisByDirId`；套装汇总按套装名计数，按件数从多到少排。
- 删除整组沿用现在的行为（直接删除，不加确认）；删除收藏夹、清空收藏夹仍有确认。

## 文案

「＋ 新建收藏夹」「＋ 新建套装」「N 组」「更多」「重命名」「清空」「删除收藏夹」「删除」。已有的 i18n 文字照用。
