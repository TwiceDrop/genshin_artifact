## Comments

- 2026-11-18：已实现（按推荐方案定稿）。
  - **位置**：账号管理放在设置页已有的「在线账号」卡片里，和原来的邮箱、用户名、退出登录放在一起。在线账号页（`/online-account`）仍保持隐藏，不启用。左下角就是侧栏底部：登录后，在「账号」上方多一行头像和用户名（没有用户名时显示邮箱），点击进入设置页。手机端的抽屉侧栏也一样。
  - **共享状态**：新增 `src/cloud/online-user.mjs`，侧栏和设置页共用同一份登录用户。收到 `mona-cloud-context-change`（登录、退出、注销）时重新读取。
  - **设置页新增**：
    - 头像：点击后弹窗，从全部角色头像里选，也可以选「不使用头像」；
    - 修改邮箱：先向新邮箱发验证码，填写后确认；
    - 修改密码：填当前密码、新密码和确认，成功后其他设备退出登录；
    - 注销账号：弹框里输入当前密码确认。
  - 忘记密码放在登录页，由任务 06 实现，这里不重复。
  - **本机网关**（`server/cloud.mjs`）：放行 `/v1/me/password` 和 `/v1/me/email`；改邮箱成功后更新缓存的登录用户；`DELETE /v1/me` 成功后清掉本机会话和 Cookie 密钥。Android 端（`src/platform/cloud-mobile.mjs`）做法一致。`cloudApi` 注销后会广播登录状态变化。测试见 `tests/cloud-gateway-account.test.mjs`。
  - **验证**：用 `vue-cli-service build --target lib` 单独构建了设置页和侧栏，通过；跑了网关测试。没有在浏览器或手机上实测。
  - **文案**：
    - 行名：头像 / 修改邮箱 / 修改密码 / 注销账号；
    - 按钮：更换头像、修改 / 收起、发送验证码（N 秒后重发）、确认修改、保存、注销账号、不使用头像；
    - 输入框占位：新邮箱、验证码、当前密码、新密码（8–64 位）、再次输入新密码；
    - 注销账号的说明：永久删除在线账号、云端档案和云端 Cookie，本机数据保留；
    - 注销确认框：注销后在线账号、云端档案和云端 Cookie 会被永久删除，无法恢复；本机数据保留。请输入当前密码确认。
    - 成功提示：邮箱已更换 / 密码已修改，其他设备已退出登录 / 在线账号已注销。
