# 02: 服务端支持改密码、改邮箱和忘记密码

**What to build:** 已登录的用户可以修改登录密码和邮箱；忘记密码时用邮箱验证码重设。

改用户名已经有了（`PATCH /v1/me`）。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 改密码：要求输入旧密码。成功后注销本设备以外的其他会话
- [ ] 改邮箱：向新邮箱发验证码，验证通过后更换；新邮箱已被占用时报错
- [ ] 忘记密码：向注册邮箱发验证码，验证通过后设新密码，并注销所有会话。对未注册邮箱的响应与已注册邮箱一致，避免借此探测邮箱是否注册
- [ ] 以上发码共用现有的发码限流
- [ ] 测试覆盖以上流程和对应的错误分支
