# 01: 服务端支持密码注册和密码登录

**What to build:** 注册时用邮箱验证码 + 用户名 + 密码建号；登录可以用「邮箱或用户名 + 密码」，也可以继续用邮箱验证码。

现状：只有验证码登录（`online-service/src/auth.mjs` 的 `requestCode`、`verifyCode`），验证成功时自动建号，`users` 表没有密码。用户名已有（`005_usernames.sql`，不区分大小写唯一）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 迁移：`users` 增加密码哈希字段。哈希用 `node:crypto` 的 scrypt 加随机盐，不新增依赖
- [ ] 注册接口：校验验证码，同时写入用户名和密码，用户名规则沿用 `setUsername`；邮箱或用户名已占用时报错
- [ ] 验证码登录不再自动建号，邮箱未注册时报错。规格要求每个账号都有密码
- [ ] 密码登录接口：按邮箱或用户名找账号，校验密码后签发会话，会话格式与验证码登录相同。错误提示不区分「账号不存在」和「密码错误」
- [ ] 限流：密码登录同一 IP 每小时 20 次（原稿要求），另加按账号计数的限流，沿用 `limit()`
- [ ] 测试：注册、两种登录、用户名登录不区分大小写、限流、未注册邮箱用验证码登录被拒
