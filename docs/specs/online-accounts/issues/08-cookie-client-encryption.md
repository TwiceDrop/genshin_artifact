# 08: 客户端在本机加密 Cookie 并上传，换设备后解密

**What to build:** 用户自己设定一个解密密码，与登录密码无关。客户端用 WebCrypto 从它派生密钥（PBKDF2，随机盐），用 AES-GCM 加密米游社 Cookie 后上传。新设备拉取后输入解密密码，在本地解密，再走现有的本地米游社导入。

细节见 `spec.md` 已定结论 1。

**Blocked by:** 04

**Status:** ready-for-agent

- [ ] 加解密模块独立成文件，接口只有加密、解密、派生密钥；密钥派生的迭代次数写进密文元数据，以后可以调高
- [ ] 本机只存派生出的密钥，不存解密密码和明文 Cookie 的副本；存储位置沿用现有 Cookie 的存放方式
- [ ] 解密密码输错时明确提示，不清空任何数据
- [ ] 修改解密密码：用旧密钥解密、新密钥加密后上传
- [ ] 忘记解密密码：提供重新导入 Cookie 并设新密码的入口
- [ ] 独立预期值测试：用固定的密码、盐和明文加密后能解开，错误的密码会失败，篡改密文会失败
- [ ] 新增界面文案先交开发者确认
