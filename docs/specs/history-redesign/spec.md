# 历史记录页重做

Status: done

2026-11-15 与开发者对齐：保留「左列表 + 右详情」两栏，换成夜空风格；详情里的角色做成头像条，五件圣遗物改用圣遗物页的卡片。

动手前先读根目录 `AGENTS.md`。颜色读 `src/styles/content-theme.css` 的 `--cx-*`，页面根带 `cx-scope`。

## Problem Statement

- 配色还是旧的蓝色（选中条、按钮、分段切换），卡片带细边框，和其他页对不上。
- 页面底块只有内容那么高，没有记录时下方一大片空白。
- 详情里的圣遗物是旧的 `ArtifactDisplay` 小块，字小、主词条不突出。
- 多人记录的 DPS、轴时长、总伤害挤在一条细框里。

## Solution

1. 页面做成和其他页一样的圆角内容块，铺满高度；标题图标金色，单次 / 多人切换用金色分段按钮。
2. 记录列表：无边框圆角行，选中行加深底色并在左侧加金色竖条；每行带角色头像（多人记录头像单独一行、略微叠放）；状态用胶囊：已完成绿、计算中金、失败红、其余暗色。
3. 详情：每个成员一块，圆形头像（金色描边）、命座胶囊、天赋；武器带图标放在右侧胶囊里；BUFF 用胶囊。
4. 五件圣遗物用圣遗物页的卡片（主词条大字、暴击暴伤金色），详情宽时一行五件，窄时自动换行，手机单列；缺的部位显示部位名和「未装备」。
5. 多人记录的 DPS、轴时长、总伤害做成三块数字，DPS 金色。

## Implementation Decisions

1. **卡片共用**：`ArtifactCard.vue` 从 `src/pages/ArtifactsPage/` 移到 `src/components/display/`（圣遗物页之后的第二处使用），加 `readonly`：渲染成 `div`、不可点、不显示锁定（锁定是仓库状态，对计算快照没有意义）。
2. **页面脚本不动**：筛选、分页、选中、取消、跳转、手机上的列表 / 详情切换和焦点返回都保持原样；只改模板、样式和组件引入。
3. **文案**：没有新增文字，沿用原有文案。

## Testing Decisions

- 没有测试引用这个页面。
- 浏览器实测：桌面深色和浅色、手机宽度的列表 → 详情 → 返回；用内存里的合成多人记录看团队详情（不写存储，刷新即消失）；圣遗物页卡片仍是可点的按钮。

## Out of Scope

- 记录的保存、加载、取消逻辑和「查看计算」跳转。
