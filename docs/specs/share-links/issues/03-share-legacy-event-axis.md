# 03 分享旧版事件轴

Status: ready-for-agent
Blocked by: 01

持有旧版事件轴的作者可以直接发布。读者能区分玩家的切人操作和后台战斗事件，也能下载回原格式。

## 验收条件

- [ ] 用带初始前台、显式切换、后台命中和治疗的合成旧轴，从正常编辑入口发布。匿名打开显示正确标题、四名角色和事件数。
- [ ] 按原事件时序展示施放、命中、治疗等记录及其归属。仅显式切换标为切人；后台角色造成命中或治疗时不会产生切人提示，摘要不会把事件数写成动作步数。
- [ ] 预览采用该格式记录的轴长和条件。匿名下载后从「导入计算配置」读取，核对旧格式标识、修订号、初始前台、轴尾命中、原事件、时间、重复与触发条件以及覆盖设置。
- [ ] 让合成输入夹带额外字段，核对公开响应与下载仅含此格式的公开配置。导入产生独立本地副本，读者无法借此取得作者的管理权限。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
