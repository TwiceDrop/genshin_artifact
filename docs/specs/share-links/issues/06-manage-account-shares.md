# 06 删除本地轴后从「我的分享」管理

Status: ready-for-agent
Blocked by: 05

作者可以整理本地配置，并从在线账号找回仍然公开的分享。即使原设备或本地轴不可用，也能取消已发出的链接。

## 验收条件

- [ ] 删除已分享的本地轴前，确认框说明原链接继续有效，可从「我的分享」取消。返回会保留本地轴，确认后本地轴消失，匿名访问原链接和下载仍成功。
- [ ] 在另一台没有该轴的设备登录同一账号，从「我的分享」按标题、状态、有效期识别分享，包含永久链接和已删除本地源的分享。
- [ ] 从账号列表执行取消并二次确认，预览与下载立即显示已取消。取消失败时可重试，列表状态反映服务端结果。
- [ ] 切换到另一在线账号后，列表只列出当前账号的分享。用该账号直接请求管理原链接也无法取消；原作者和持链读者看到的有效状态正确。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
