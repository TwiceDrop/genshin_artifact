# 02 在手机和桌面阅读长轴

Status: done
Blocked by: 01

读者用手机能看清长轴的起手和换人，桌面可从摘要进入只读时间轴总览。呈现以动作轴公开快照为准。

## 验收条件

- [x] 用含长标题和连续动作的合成轴核对 390 像素宽手机首屏。标题完整折行，可见队伍、初始前台和起手，底部固定下载按钮不会遮住最后一条记录。
- [x] 同角色连续动作归组，显式切换只出现一次。点头像高亮其全部行动段，其余段仍保留顺序；再次点击或选择显示全部可恢复。
- [x] 从快照读取动作参数、命座条件及条件时序。起手为 0 秒时如实显示，无法确定的总时长或区间留空；最后一次动作的时刻不能当作整条轴的时长。
- [x] 桌面按设计稿双栏显示摘要、下载和详情。有足够时间数据时可切换只读时间轴总览；窄屏使用单栏和分段视图。
- [x] 公开页默认夜空深色，品牌及角色头像从本站加载。模拟单张头像加载失败，名称、元素色和角色首字仍可识别，阅读与下载均可继续。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
