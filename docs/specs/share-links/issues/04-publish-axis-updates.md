# 04 把修改发布到原链接

Status: done
Blocked by: 01

作者可以比较本地轴和已发布快照，选择发布时机。多台设备同时编辑时，作者能看见新发布的版本并决定是否覆盖。

## 验收条件

- [x] 分别仅改顺序、参数或条件，手动保存与自动保存均保留原链接上的旧版。已分享入口和列表显示待更新，手动保存显示文1，自动保存安静更新状态。
- [x] 打开弹窗时核对服务端版本，按设计稿展示线上和本地摘要、文3及主按钮「发布更新到原链接」。离线时将缓存标为上次发布。复制原链接显示文4，暂不发布可关闭并保留修改。
- [x] 带未落盘的有效草稿发布，先保存再更新。读者重新打开同一网址，页面与下载均显示新版，到期时刻与首次发布时相同，读者先前导入的副本保留原内容。
- [x] 用同账号的两个设备发布。同一版本已有更新时，后发设备保留本地草稿、显示最新线上摘要，重新确认后才覆盖。其他账号或未登录的更新请求不能改变公开版本。
- [x] 模拟本地保存失败、更新请求失败及重复提交，核对线上始终是完整快照，界面仅在服务端确认成功后显示发布成功。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
