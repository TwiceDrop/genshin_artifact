# 05 选择有效期、取消分享与查看失效原因

Status: ready-for-agent
Blocked by: 01

作者可以选择公开期限或提前结束分享，读者访问预览和下载时能区分链接状态与临时故障。

## 验收条件

- [ ] 首次分享提供 7 天、30 天、永久，默认 30 天。用可控服务端时间核对每个有限期限的截止前和截止时刻，永久链接持续可访问。
- [ ] 在分享弹窗内点取消分享，原位展示文5。返回后原链接仍有效，确认后立即停止提供快照，本地轴仍可用。请求失败时保留管理关联并显示原因，只有当前发布者可以取消。
- [ ] 分别请求预览和下载。过期得到 `410 SHARE_EXPIRED`，已取消得到 `410 SHARE_REVOKED`，未知地址得到 `404 SHARE_NOT_FOUND`。失效响应均不包含轴内容，重新打开不会读到旧缓存。
- [ ] 过期与已取消页分别使用已确认的标题、文9和文10。断网或服务故障时可重试，恢复后有效链接仍可打开。
- [ ] 同一轴在到期或取消后重新分享会得到新网址，原网址继续显示对应失效原因。读者曾经下载的文件仍可导入。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
