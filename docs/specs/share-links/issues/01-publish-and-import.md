# 01 发布动作轴并下载导回

Status: done
Blocked by: None

作者从编辑器发布动作轴，读者用浏览器打开链接，下载同一份已发布快照，再从莫娜导入。本项先走通默认 30 天这一档。

## 验收条件

- [x] 在离线模式编辑一条合成动作轴，从「导出」旁点「分享」。登录莫娜在线账号后仍能核对原草稿、轴名和队伍。仅打开、关闭弹窗或完成登录均不发布。未登录的创建请求被拒绝。
- [x] 作者确认时先校验并保存当前草稿，成功后才创建归属于该在线账号的快照。校验或保存失败能看到具体原因。首次分享和已分享弹窗跟随内容页深浅色，首次分享采用文2。
- [x] 生成的 HTTPS 链接只携带随机公开标识。成功后复制并显示完整地址；在剪贴板拒绝、重复点击或创建成功后重试时，作者仍可手动取得同一链接。
- [x] 用未登录浏览器打开链接，看见标题、四名角色、初始前台与动作顺序。下载 `.mona-axis.json`，按照文6从「多人优化 → 导入计算配置」导回。比对格式、成员、顺序、时间、动作参数、条件分支与轴尾命中，导入后可独立编辑。
- [x] 发布与读取仅传递该轴格式的公开字段。使用带额外嵌套字段的合成输入，检查公开响应和文件不会夹带账号、UID、库存、私有任务、Debug 或分享管理信息。默认期限从服务端创建成功起算，满 30 天时预览和下载均停止提供快照。

产品行为与界面文案以[四人轴分享链接规格](../spec.md)为准。
