# 四人轴分享链接

Status: done

## 玩家遇到的问题

攻略作者想把四人轴发到群聊或写进攻略。读者用手机点开就想看队伍和操作顺序，有需要才下载到莫娜使用。作者之后调整动作时，希望沿用已发出的地址，也希望能在约定时间或主动取消时结束公开访问。

## 使用方案

作者在「多人优化 → 管理计算配置」中选中一条轴，通过「分享」发布一个快照。拿到链接的人可以在浏览器中查看、下载当前发布版本。作者可以继续在本地编辑，点「发布更新到原链接」后，读者再次打开原网址即可看到新版。删除本地轴后，作者仍可以从在线账号的「我的分享」取消链接。

## 用户故事

1. 作为离线编辑的作者，我希望点分享后可以登录，并在重新进入多人优化时恢复刚才的草稿，以便确认要发布的内容。
2. 作为作者，我希望先核对轴名、队伍和摘要，再选有效期，以便把正确的轴发给读者。
3. 作为作者，我希望浏览器拒绝复制时仍能手动复制已生成的链接，以便继续分享同一个地址。
4. 作为手机读者，我希望免登录看到队伍、初始前台和起手动作，以便在群聊里直接读攻略。
5. 作为读者，我希望能高亮一个角色，同时看到前后的动作，以便理解切人与连招。
6. 作为旧版事件轴的读者，我希望看清技能施放、后台命中和治疗，以便分清操作和战斗中发生的事件。
7. 作为读者，我希望下载后从「导入计算配置」直接使用，并保留条件、参数和覆盖设置。
8. 作为作者，我希望保存和自动保存都只改本地版本，以便在发布前反复试轴。
9. 作为作者，我希望比较线上版本与本地修改、决定何时更新，以便攻略里的链接继续有效。
10. 作为跨设备使用的作者，我希望发布时发现另一台设备已更新，以便决定是否覆盖。
11. 作为整理本地配置的作者，我希望删除本地轴后仍能从账号里找到并取消自己的分享。
12. 作为读者，我希望区分过期、作者取消、地址不存在和临时网络故障，以便决定联系作者还是重试。

## 实现决定

### 发布、归属与有效期

- 在线服务保存分享记录。记录关联发布者的莫娜在线账号，具有独立的随机公开标识、当前发布快照和版本、发布时间、可为空的到期时间以及取消状态。链接使用公网 HTTPS 地址，仅携带公开标识。发布、更新、列出自己的分享及取消均检查账号归属。浏览、下载免登录。
- 发布者未登录时引导登录，登录成功后进入首页。同一会话内重新进入多人优化时恢复原轴和草稿，再由作者确认发布。仅打开或关闭弹窗不会发布。首次发布或更新前先校验并保存当前草稿，失败时显示具体原因，保留已有线上版本。
- 创建时可选 7 天、30 天、永久，默认 30 天。有限期从服务端创建成功的时刻起算。更新沿用网址和原到期时刻。到期或取消后重新分享生成新网址；已下载的文件是读者自己的副本。
- 初次发布后自动复制链接。创建成功但剪贴板失败时进入已分享状态，保留可选取的完整地址。再次复制沿用该地址。取消分享使用弹窗内的二次确认，服务端取消成功后才清除本地有效分享关联。
- 编辑、手动保存和自动保存均不对外发布。待更新按可分享内容判定，能识别只改顺序、条件或参数的情况。手动保存有修改的已分享轴时显示文1，自动保存只更新入口状态。
- 本地保存上次发布版本、内容标识及摘要。打开分享弹窗向服务端核对，离线时摘要只能标为上次发布。发布时按已核对的版本更新；期间若其他设备已发布，保留草稿和新线上版本，展示最新摘要，由作者重新确认。请求失败或重复提交不得造成额外有效链接、部分更新或虚假的成功提示。
- 编辑页删除已分享的轴只删除本地数据。删除确认要说明原链接继续有效，作者可以从「我的分享」取消。该入口按当前在线账号列出分享，能识别标题、状态和有效期，支持找到并取消已删除本地源的分享。撤销分享本身保留本地轴。

### 公开内容与两种轴格式

- 预览和下载取同一份已发布快照。发布端及在线服务的公开接口按轴格式取公开字段，保留重新导入需要的字段和嵌套参数。账号、UID、库存、私有计算任务、历史、Debug 和导入文件夹带的额外字段均不进入公开响应或下载文件。作者填写的轴标题属于公开内容。
- 动作轴保留四名角色、初始前台、动作和切换的时间与顺序、条件分支、动作参数、轴尾命中及格式和规则信息。公开页按连招归组，显式切换只标记一次。条件动作保留条件含义。只有快照能确定的时刻、区间和轴长才显示；起手时间为零合法。仅凭末条记录的时间无法确定整条轴的时长。
- 旧版事件轴保持原格式，保留原事件、时序、重复与触发条件、覆盖设置及轴长。页面按事件呈现，只有显式切换记录才标记切人。后台命中、治疗或反应仍归属于对应角色。摘要区分动作步数和事件数。
- 两种格式都下载为可从「多人优化 → 导入计算配置」读取的 `.mona-axis.json`。导入得到独立的本地配置，后续发布、取消和到期只影响线上访问。下载内容不携带原作者的分享管理关联。

### 交互与失效状态

- 发布弹窗跟随客户端内容页深浅色，沿用四人轴编辑区的保存、用于计算、导出和删除。分享入口跟在导出旁。首次分享、已分享、待更新、原位取消确认四种状态采用设计稿布局。待更新时突出「发布更新到原链接」，「复制原链接」仍可复制线上版本。
- 公开页默认夜空深色。手机单栏，顶部显示轴名、队伍、初始前台，底部固定下载按钮。桌面双栏，左侧摘要及下载，右侧详情，有足够时间数据时提供只读时间轴总览。点击角色头像高亮其记录，再点可恢复全队。长标题完整折行，长列表末尾仍能读到。角色与品牌资源随公开页同站点部署，缺图时保留元素色、角色首字和名称。
- 预览和文件下载均在读取时判断有效性。到期返回 `410 SHARE_EXPIRED`，取消返回 `410 SHARE_REVOKED`，查无链接返回 `404 SHARE_NOT_FOUND`。失效响应不含轴内容。公开访问每次重新打开能读到当前状态。网络和服务故障提供重试，不显示为过期或取消。

## 验收方式

验收从作者的编辑页及「我的分享」、读者的匿名浏览器及客户端导入入口出发。在线服务的账号、公开响应和并发用例沿用现有账号与云档案 HTTP 测试方式，轴文件往返沿用四人轴合成夹具与真实导入入口。以读者实际收到的内容、作者可见的状态和文件重新导入的语义为准。

1. **创建与下载。** 在未登录状态编辑后发起分享，登录进入首页，再进入多人优化核对草稿并发布。用另一未登录浏览器打开、下载并导回。两种格式各用一份合成数据，对照标题、成员、顺序、条件和各自格式专有字段，检查公开接口和下载中没有夹带的额外字段。另一个在线账号不能管理作者的链接。
2. **原链接更新。** 发布后只改动作顺序，分别自动保存、手动保存和复制原链接，匿名读者仍看到旧版。主动发布后，原地址的预览和下载均更新，到期时刻相同。模拟第二设备抢先更新、草稿保存失败与剪贴板拒绝，检查各自的可见结果。
3. **期限与撤销。** 覆盖默认 30 天、7 天和永久。在到期前及到期时分别读取预览和下载。取消确认可返回，确认后立即停止提供内容，重新分享得到新地址。对照三种失效响应与网络故障。
4. **删除与账号管理。** 删除本地轴后匿名访问仍成功，从同账号「我的分享」找到它并取消，重新访问即失效。切换账号后列表和管理权限随账号切换。
5. **两端阅读。** 手机核对首屏、长标题、连续动作、角色聚焦和底部下载；桌面核对摘要、版本对照和时间轴总览。旧轴包含显式切人和后台治疗或命中，核对只在真实切换处出现切人标记。头像资源加载失败、条件时序和无法确定的总时长分别核对。

## 本地验收记录

- 使用合成账号、真实 HTTP 接口和临时 PostgreSQL 兼容数据库核对了两种轴格式的往返、权限隔离、并发版本冲突、有效期边界、撤销及故障重试。
- Chrome 通过本机网关完成登录返回、首次发布、匿名阅读、文件下载与导回、更新、删除本地轴及从账号撤销。桌面和 390 像素宽视口均走公开页，另行模拟了剪贴板拒绝、头像加载失败及本地保存失败。
- 客户端构建成功。在线服务的部署包包含迁移、公开页、字体和 19 名角色的头像。公网 HTTPS 与 Android 真机仍待部署后验收。

## DSL 和角色预设分享

- 在「配装计算 → 目标函数」从 MONA-DSL 编辑器或 DSL 生成器分享当前源码。读者可切换自动换行、复制原文，界面使用文7。
- 在角色页的「预设」菜单分享当前选中的角色配置，也可从配装计算的预设菜单分享当前配置。公开页列出角色、武器、天赋、目标函数、敌人、套装及词条限制与启用的 BUFF。作者主动勾选「附带当前穿戴圣遗物」才发布穿戴明细，默认使用文8。
- 两类内容均由作者登录后确认发布。有效期可选 7 天、30 天（默认）或永久。每个链接指向发布时的快照。读者免登录打开，作者可在「我的分享」复制和撤销。只有四人轴提供原链接更新。
- 预设只传递公开展示字段。游戏预设名可能包含 UID，因此默认以角色名生成公开标题。仓库、圣遗物 ID、米游社标识和账号均不进入分享请求。

Chrome 本地验收覆盖手写和生成的 DSL、登录返回、手机换行和源码复制；角色页分别发布不带装备和带一件装备的预设，并检查发送内容中没有仓库 ID 或另一件未穿戴装备。在线账号撤销预设后，匿名访问返回 410，同账号的 DSL 链接仍可打开。

## 范围以外

本期不含自动发布、原链接续期、客户端一键唤起、分享广场、评论、点赞、浏览统计或个人主页。
