# Windows 四人轴积木编辑器

目的：用鼠标直接安排技能时间，替代 Windows 上逐行填写动作表格。

- Windows 使用四条角色轨道与技能积木；其他平台保留原编辑器。
- 时间轴只有四条角色行。BUFF以不同颜色、2px高的细长条贴在所属角色积木底边，保留透明的鼠标命中区域；悬停显示名称、来源角色、起止时间与分支概率，提示跟随指针并限制在窗口内。选中积木后在轴下显示其命中倍率，不再增加BUFF行或倍率行。
- 从角色技能库拖入、移动已有动作、删除、精确编辑时间和动作参数，保留同时间动作的原始顺序与上下调整。
- 原始动作轴格式、保存入口、账号存储不变。拖动结束后一次提交；取消拖动不改轴。
- 100ms 吸附；横向滚轮与 Shift+滚轮、底部滚动条、边缘自动滚动及延长画布。
- 跨角色轨道对齐技能起点与已校准技能末尾；选中后左右方向键每次移动0.1秒，Del删除。只移动所选动作，不顺延其他动作。拖动浮块与落下后的积木共用文字排版。
- 拖动时距其他技能边缘32px内吸附，优先选择附近积木的显示末尾，再对齐起点，显示贯穿角色轨道的竖向虚线；离开范围时落点使用0.1秒网格。先按鼠标原始位置判断吸附，再做网格取整，避免阈值被取整缩窄。未标定动画的动作仍使用标签宽度，但宽度调整至0.1秒网格对应的134.4px，使其可见末尾也能精确贴齐；该显示宽度不写作角色动画时长，不改变引擎规则。
- 拖动浮块位置逐像素跟随鼠标，仅落点时间保留0.1秒精度；位置更新合并到动画帧，与边缘滚动共用一次定位。吸附采用80ms短过渡，保留32px范围与末尾优先；系统要求减少动态效果时取消过渡。
- BUFF可见细条放在积木选中描边下方1px，仍为2px粗；透明命中区高5px，与相邻BUFF间距一致，避免被积木遮挡或相邻细条互抢悬停。覆盖起止时间不变。
- 已核实的施放帧数按60FPS换算秒数并保留一位小数，决定积木宽度；[来源与未完成项](cast-timing.md)。沃雅妮莎动画帧数仍未闭合。
- 从技能栏拖入、移动已有积木和正式落点共用同一套宽度计算。用现有引擎解析临时落点的角色状态，同步取得动画时长，不依赖异步倍率预览返回。目的：消除预览固定132px、落下后才缩短的问题，并保证跨状态移动的长度一致。公共动画预览独立于WASM计算，和倍率预览共用角色配置及动作时长提取，避免重复状态判断。
- 自动刷新技能倍率与引擎输出的持续窗口、效果激活/刷新/耗尽区间。使用原倍率预览的角色参数和无装备预览上下文。
- 沃雅妮莎「十二弦的泪歌」以实际前后台次数池的有效区间并集显示一条覆盖线，替代旧的固定30秒占位窗；计算中的两个次数池独立消耗。角色包声明窗口与效果的对应关系，预览层不按相似名称猜测去重。
- 爱可菲「灵感浸入调味」的预览与伤害规则共用触发命中和12秒到期定义；持续命中刷新时合并连续覆盖，保留过期后的空档，未解锁天赋不画条。公共覆盖合并模块只处理显示区间，避免两个角色各自重复编写区间合并。
- 技能栏中每个角色可选择0–6命，仅用于BUFF预览。初始采用当前角色命座，临时选择不写入动作轴、角色配置、导出或计算条件；切换动作轴后重置。BUFF窗口使用独立角色副本求值，技能倍率和动画宽度继续使用原角色配置，避免预览命座污染计算输入。
- BUFF悬停保留名称与时间，下方显示效果和数值，不单列作用对象（开发者已确认）。固定效果显示百分比，面板或层数相关效果显示公式、上限与初始次数；这些值跟随预览命座和角色天赋配置。角色包提供详情并与计算共用常量或内核取值，页面只展示文本。提示框按实际尺寸限制在窗口内。
- 自动预览合并等待50ms，Worker常驻预热；同一时刻只有一个计算任务，期间新编辑仅保留最新输入，旧返回不覆盖新轴。目的：消除每次编辑重复加载内核的延迟，避免快速按方向键时旧结果回写。

覆盖边界：当前引擎未输出生命周期区间的角色被动、装备效果不推测持续时间。BUFF轨道尚不代表全部增益；需要后续为这些规则补充统一的观测数据。技能倍率仍沿用原倍率预览定义，不是最终伤害。

本机预览更新使用 `npm run build:local -- --no-clean`，保留已有页面引用的哈希资源。目的：已打开的编辑器在每次修改后会重新创建Worker；清理旧资源会使其加载404，BUFF和倍率同时消失。已复现“旧页面→替换构建→Worker 404、错误message为空→无BUFF且无错误提示”，补回旧资源后验证恢复。加载失败提示文案已由开发者确认：“技能预览加载失败，请刷新页面后重试。”此规则只用于正在提供预览的构建目录，正式发布仍按发布流程准备。

验证：6 项 Node 测试通过；Windows 桌面生产构建通过（既有样式顺序与包体积警告）；独立 Chrome 测试上下文中，四条角色行、2px细条、BUFF悬停提示与窗口边界、拖入、移动、横向滚轮、Shift+滚轮、边缘滚动、取消、保存重开及删除均通过，无页面异常。Windows 实体鼠标横向滚轮仍需开发者实机验收。

后续修订验证：12项定向Node测试通过；浏览器验证跨角色末尾吸附、左右键、鼠标拖放后Del、浮块与积木字体一致、单次创建常驻Worker。单个芙宁娜Q合成轴的预热后更新观测为68ms（包括50ms合并等待；非性能保证）。旧页面跨构建更新的复现由Worker 404/BUFF消失变为旧资源200/BUFF正常增加。生产构建和4183预览资源核对通过。

预览宽度回归：修正前浏览器复现芙宁娜E的新拖入预览132px、落下57.59375px；修正后新拖入、移动预览、落下均为57.59375px，抓取偏移和落点一致。13项定向Node测试通过，覆盖同步动画预览与倍率预览一致，以及丝柯克跨状态移动；生产构建通过。

BUFF修订及命座预览验证：19项定向Node测试通过，包含重复窗口、爱可菲命中刷新与空档、天赋解锁、同时间伤害边界、命座副本隔离及50ms预览调度。独立Chrome合成轴验证沃雅妮莎泪歌只有一条、爱可菲减抗条与悬停正常、细条保持2px；四个命座选择可操作，二命BUFF和覆盖时长随选择更新，回到零命移除相应条。切换前后技能倍率、积木宽度与导出JSON一致。Windows网页构建通过，4183本机预览已更新。

悬停详情验证：20项定向Node测试通过，包含角色数量对应减抗、气氛值每层和上限、预览命座隔离、吸收裂隙数与凋尽10次命中上限。独立Chrome实际悬停确认效果、公式、上限和次数可见，切换命座更新数值，不显示“作用对象”字段，长提示与靠近顶部的提示均在视口内，无页面异常。Windows生产构建通过，4183及旧Worker资源均返回200。

`skirkC2` 窗口显示名已按开发者确认改为“凋尽”，与零命也能生成该窗口的实际规则一致。

遮挡与吸附修订验证：浏览器复现细条可见区域落在积木底边内，修复后位于选中外框下方1px，厚度仍为2px；叠放积木、多BUFF命中区互不遮挡及悬停通过。跨角色拖动实测距起点/终点14px时吸附并显示竖线，20px时脱离吸附，松手保存准确的对齐时间。15项定向Node测试通过；Windows构建和4183预览更新完成。截图中的七相一闪0–0.7秒窗口时长保持引擎原值。

扩大吸附范围验证：7项定向Node测试通过；浏览器实测距末尾28px时贴齐、36px时脱离，松手保持末尾时间，附近同时有更近起点时仍优先末尾。32px版本Windows构建及本机预览已更新。

拖动流畅度验证：浏览器以1px步进拖动20次，修复前仅4个不同位置且每次跳约6.4px，修复后20个不同位置、每次移动1px。边缘自动滚动、Escape取消、80ms吸附过渡和松手后准确贴齐末尾均通过；Windows构建与4183本机预览更新完成。

普通攻击吸附回归：17项定向Node测试通过；浏览器复现截图的爱可菲普攻与沃雅妮莎普攻，确认拖动时显示对齐线，预览与松手后均贴齐可见末尾，同角色及跨角色边缘间隙均小于0.05px，落点2.1s且保持同一层。Windows构建及4183预览已更新。
