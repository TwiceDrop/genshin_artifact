# 05: Android 发送通道

**What to build:** Android 客户端用原生请求把使用统计发到在线服务，行为和桌面端一致：入口访问自动记录、按天去重、离线补发、常量为空时不启用。

**Blocked by:** 04

**Status:** ready-for-agent

规格见 `docs/specs/usage-stats/spec.md` 的「发送通道」。

- [ ] Android 的发送实现沿用现有在线账号的原生请求做法，作为使用统计模块的一个注入实现，模块本身不改
- [ ] 不复用在线账号的会话或凭据
- [ ] 平台字段上报为 Android
- [ ] 补充发送实现的测试，覆盖成功、失败返回和网络异常三种情况
- [ ] 验证：只跑相关测试；真机验收由开发者完成，汇报时写清没有在真机上跑过
