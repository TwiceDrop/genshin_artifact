# 07: 关键动作的记录调用

**What to build:** 规格里的 14 项关键动作在成功的那一刻各记录一次，开发者在统计页面上能看到每项动作有多少人实际执行过，而不只是页面被打开过。

**Blocked by:** 04

**Status:** ready-for-agent

规格见 `docs/specs/usage-stats/spec.md` 的「功能清单」中的关键动作表。

- [ ] 每项动作在成功的地方调用一次"记录功能 ID"，失败或取消时不记录
- [ ] 单人配装：伤害模式和面板模式跑完都记
- [ ] 动态圣遗物评分：跑完时记
- [ ] 四人轴计算：评估和搜索跑完都记
- [ ] 米游社/HoYoLAB 导入、导入圣遗物文件：导入成功时记
- [ ] 导出数据：账号页和圣遗物页的导出都记
- [ ] 保存预设、保存圣遗物组：保存成功时记
- [ ] 清空已选：点击时记
- [ ] 切换外观、切换语言：选择后记
- [ ] 检查更新：手动检查时记，自动检查不记；安装更新：开始安装时记
- [ ] Debug 导出：配装页和四人轴页的导出都记
- [ ] 记录调用不改变任何计算的输入、输出和时序
- [ ] 每项的触发位置和核对结果写在本文件的 Comments 里
- [ ] 验证：一致性测试检查每个关键动作的功能 ID 至少被调用一处；其余逐项手动核对，汇报时写清哪些在浏览器里点过
