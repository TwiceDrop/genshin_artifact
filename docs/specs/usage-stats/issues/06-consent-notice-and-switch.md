# 06: 首次提示与设置开关

**What to build:** 新安装或升级的玩家第一次启动这个版本时看到一次使用统计提示，可以选"知道了"或"关闭统计"；做出选择之前不上报。设置页里随时可以开关；关掉后立即停止上报，清空本地队列，删除匿名安装 ID，重新开启时生成新的 ID。

**Blocked by:** 04

**Status:** ready-for-agent

规格见 `docs/specs/usage-stats/spec.md` 的「客户端的使用统计模块」。

文案按初稿实现，开发者定稿后再改文字；定稿前不发版。初稿："为了解哪些功能有人在用，莫娜会匿名统计功能使用次数，不包含 UID、角色、圣遗物或计算数据。可随时在设置中关闭。"

- [ ] 首次提示在版本内第一次启动时显示一次，桌面 UI 和移动 UI 都有
- [ ] 玩家在提示里做出选择之前不上报（2026-11-12 开发者确认）；记录可以先进本地队列
- [ ] 设置页新增开关，和外观、语言放在一起
- [ ] 关闭：立即停止发送，清空队列，删除匿名安装 ID
- [ ] 重新开启：生成新的匿名安装 ID
- [ ] 上报地址常量为空时，不显示首次提示，设置页也不显示开关
- [ ] 模块测试覆盖：选择前不发送、关闭后队列和 ID 都被清掉、重新开启后 ID 变了
- [ ] 验证：只跑相关测试；在浏览器里点一遍提示和开关，截图核对两种 UI
