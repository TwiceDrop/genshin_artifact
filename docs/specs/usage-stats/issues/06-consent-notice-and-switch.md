# 06: 首次提示与设置开关

**What to build:** 新安装或升级的玩家第一次启动这个版本时看到一次使用统计提示，可以选"知道了"或"关闭统计"；做出选择之前不上报。设置页里随时可以开关；关掉后立即停止上报，清空本地队列，删除匿名安装 ID，重新开启时生成新的 ID。

## Comments

- 2026-11-12：同意状态存在本地，由记录模块管理，有三种取值：未回答（`null`）只记录、不发送；`on` 记录并发送；`off` 不记录，并删除队列、已发送列表、匿名安装 ID、最近失败和最近发送时间。选择"开启"后会立即发送一次。
- 提示框不能用关闭按钮、点遮罩或 Esc 关掉，只能选两个按钮之一。点"清空本地存储"会连同意状态一起清掉，下次启动会再提示一次。
- 文案按初稿实现，中英文都加了（`src/i18n/locales/` 的 `usageStats`）。英文是我翻译的，和中文一样需要开发者定稿；定稿前不发版。
- 验证：
  - 记录模块和路由钩子的测试共 15 项通过，在线服务端到端测试 2 项通过。
  - 用测试构建（上报地址指向本机）在浏览器里实测了桌面版：提示正常显示；点"关闭统计"后本地只剩同意状态，设置页开关为关；打开开关、切换外观、刷新后，记录成功发出，并生成了新的匿名安装 ID，提示不再出现。
  - 移动 UI 用 375×812 视口实测：提示以底部弹层显示；点"知道了"后，之前排队的两条记录立即发出；设置页开关为开；控制台没有报错。
  - 移动版是浏览器里的移动构建，不是 Android 真机，所以平台上报的是 windows。
