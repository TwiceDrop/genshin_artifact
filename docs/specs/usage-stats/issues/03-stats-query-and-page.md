# 03: 统计查询与统计页面

**What to build:** 开发者打开在线服务的 `/admin/stats`，输入一次管理员 token，就能看到每个功能的累计人数、近 7 天人数、近 30 天人数、占近 30 天活跃安装的比例，以及每日活跃安装数的折线，并可以按平台和版本筛选。过期明细每天自动清理，累计人数不受影响。

**Blocked by:** 02

**Status:** ready-for-agent

规格见 `docs/specs/usage-stats/spec.md` 的「在线服务」。

- [ ] 查询接口：按平台、版本筛选，返回每个功能的四项数字和每日活跃安装数序列；没有 token 或 token 错误时拒绝
- [ ] 管理员 token 作为 Compose secret 提供，初始化脚本在缺失时生成，不打印内容，不覆盖已有文件
- [ ] 统计页面由在线服务直接提供：静态页面，显示登记模块里的中文名称；token 只存在当前标签页的 sessionStorage 里；图表库从本地引入，不走外部 CDN；不接入主前端的 Vue 构建
- [ ] 后台任务每天删除 400 天前的明细，累计汇总表不受影响
- [ ] 部署说明补充新 secret 的位置和统计页面的地址
- [ ] 测试用合成的安装 ID 和日期构造数据，手算四项数字作为独立预期值，和接口返回值比较；覆盖 token 拒绝、筛选、过期清理后累计数不变
- [ ] 验证：只跑在线服务的相关测试；统计页面在本地起一次服务，用浏览器打开并截图核对，汇报时写清是本地服务加合成数据
