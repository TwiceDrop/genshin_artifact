# 06: 桌面与手机双端人工验收

**What to build:** 在完成 01～05 后，由开发者在真实浏览器（桌面宽屏 + 手机窄屏，浅色 + 深色模式）实测整套新手引导流转与视觉效果。

**Blocked by:** 01, 02, 03, 04, 05

**Status:** ready-for-human

## 验收清单

- [ ] **自动化收口**（可在人工实测前由 agent 执行）：
  - `node --test tests/onboarding.test.mjs tests/first-use.test.mjs` 全部通过
  - `npm run build:local` 构建成功无新增报错
- [ ] **首次欢迎卡与排队**：
  - 全新空存储打开时，先显示用量统计提示，关闭后弹出「欢迎使用莫娜占卜铺」
  - 已有 `mona.firstUseDone = 'true'` 的老用户不自动弹出欢迎卡
  - 点「先导入我的数据」可正常展开并跳转 UID / 圣遗物导入弹窗 / 云端（登录时）
  - 点「先自己逛逛」后刷新页面不再弹出
- [ ] **快速了解**：
  - 从欢迎卡或引导中心启动，3 步都留在当前页。第 1、3 步高亮位置准确，第 2 步直接居中显示，键盘 `←` / `→` / `Esc` 正常
  - 完成后引导中心显示「已完成」标记，点击「再看一遍」可重放
- [ ] **6 套详细引导与降级**：
  - 从侧栏「使用引导」、设置页及各核心页顶栏 `?` 按钮均可打开对应引导
  - 动态元素未显示时（例如多人优化空态无配置下拉框）自动居中展示卡片，不卡死、可继续下一步
- [ ] **双端与双主题**：
  - 桌面宽屏（≥ 1280px）与手机窄屏（390px）气泡/底部卡片均无遮挡、无溢出，浅色/深色主题下文字对比清晰
