这里是DSL页面要实现的功能，本文只做指示，不做任何代码修改建议

1.目的：现在角色有很多种手法，每一种手法的伤害、反应都不一样，所以需要用户手动制作、或从在线服务下载相关角色的计算函数

2.目前原始DSL能计算的：
引用角色指定技能倍率	支持
同一技能多次独立声明	支持
独立技能参数	支持
独立元素附魔	支持
融化、蒸发、超激化、蔓激化	支持
普通聚变反应伤害	支持
已适配的直接月反应、星反应伤害	支持
暴击、非暴击、期望伤害	支持
伤害次数与权重	支持
读取攻击、生命、精通、充能等属性	支持
算术、比较、条件选择	支持
作为单人配装目标函数	支持
作为词条收益计算目标	支持
作为动态评分目标	支持
每段技能独立选择外部 BUFF	支持
每段技能独立设置角色、武器效果状态	支持
每段技能独立属性图	支持

3.这个页面具体要做什么？
3.1选择角色
3.2管理所选角色的DSL
3.3生成器放入DSL管理页面里，可以在管理页面直接添加、编辑、删除
3.4把BUFF等其他对DSL起作用的项目也纳入过来
3.5分享 在线分享功能
3.6导入导出功能

4.完成步骤
4.1第一次，根据我的需求，完成3.1-3.4、3.6的开发文档，新建一个dsl_save_spec.md放在与本文件的相同目录
4.2整理需求，并实现3.1-3.4、3.6的功能，并为3.5预留UI，但不做后端代码
4.3 3.5项只有得到我的明确指令才制作
