# DSL 管理开发规格

Status: needs-triage

## 问题与目标

同一角色可以使用多套手法，每套手法的技能顺序、伤害与反应可能不同。玩家需要在侧栏「我的仓库」下的「DSL管理」页面选定角色，维护该角色的多套 MONA-DSL 计算函数，并通过本地文件交换。后续实现沿用现有的 DSL 求值能力。

本文件完成 [需求指示](./dsl_save_instruction.md) 的第 4.1 步，覆盖 3.1 至 3.4 及 3.6。4.2 阶段先交付本地管理和文件交换。3.5 的在线分享与下载随后获开发者确认，行为见下方「在线分享与分发」。

## 前端页面与交互

### 页面范围与组件体系

本次改造基于现有独立的 DSL 管理页面，沿用既有的侧栏入口与页面标题。前端统一使用项目现有的 shadcn 风格组件与主题，优先复用 UiButton、UiDialog、UiSelect、UiDropdownMenu 等 Vue 3 封装，并搭配 Radix Vue 无障碍控件完成焦点管理、键盘操作与弹层交互。

### 核心交互交付

页面顶部显示当前角色的头像和名称，点击后打开头像网格，支持按元素筛选和按名称搜索。五星角色排在四星角色前，两种星级连续排列。点击头像卡片切换角色。列表首项展示所选角色的内置默认目标函数及现有说明。此项只读，下面是该角色的本地 DSL 条目。

用户可在 DSL 管理页面直接新增、编辑和删除条目。操作完成后，列表和当前内容同步更新为最新结果。

原有 DSL 生成器直接放入 DSL 管理页面并支持编辑。生成器完整复用既有能力与语义，涵盖技能段、命名状态、状态外部 BUFF、角色及武器效果覆盖与源码预览，并保留手写 DSL 源码的直接编辑能力。

页面允许编辑供命名状态选择的 BUFF 及其参数。选用的 BUFF 写入各自的命名状态，未选用的 BUFF 留在当次编辑草稿。

页面提供本地导入与导出入口。成功导入后显示新条目，文件异常时显示具体原因，取消操作保留原状态。

### 桌面与手机端可观察验收

在桌面端常见视口下，用户从侧栏进入 DSL 管理页面后，可完成角色选择、查看内置函数、条目管理、生成器与状态 BUFF 配置、手写 DSL 编辑及导入导出。弹层与下拉菜单支持鼠标和键盘操作，长源码可滚动查看。

在手机端常见视口下，上述全部流程均可通过触控独立完成，列表与表单区域可顺畅纵向滚动，关键操作控件不被裁切，弹窗与菜单在窄屏下完整可见并可正常关闭。

### 4.2 页面布局

页面顶部提供角色选择、新增、「导入文件」、「导入链接」和「在线更新」。默认目标始终显示，标题旁标金色「默认」。卡片显示内置说明和已核对的技能段，并可展开项目现有的 MONA-DSL 或对应的仓库 Rust 源码。手法卡片提供分享与导出，本地条目还支持编辑和删除。编辑窗口按来源显示生成器或手写源码。生成器的 BUFF 和武器选择放在可折叠区。计算器继续提供 MONA-DSL 源码入口和生成器入口。

## 本地数据、计算与文件交换

### 角色归属与条目保存（3.1、3.2）

- 每条 DSL 条目对应一个角色。归属用项目已有的角色标识表达，界面语言或显示名称的变化不改变归属。同一角色可以保存多套手法。
- 独立的管理条目应保留名称、所属角色和完整的 MONA-DSL 源码。通过生成器维护的条目还要保留能重新打开编辑的生成器配置。仅有手写源码的条目继续按源码保存。
- 保存和编辑以单条记录为单位。切换角色、打开编辑、预览和取消不会写入。删除只作用于选中的已保存条目。现有角色预设里的 DSL、角色、武器、圣遗物和 BUFF 数据继续按原语义读取。
- 管理条目使用现有本地存储，按本地账户和角色隔离。角色预设继续管理其原有的 DSL 数据。

### 生成器与计算条件（3.3、3.4）

- 生成器输出沿用现有 MONA-DSL 源码和逐段解析规则。保存生成器条目时，源码与生成器配置应反映同一次修改。从旧预设或交换文件取得的手写源码按原文本保留，适用现有源码编辑和解析能力。
- 基础设置和逐段设置按现有计算语义区分。未指定状态的伤害和属性声明沿用本次计算的基础角色、武器、圣遗物效果、敌人和启用的外部 BUFF。命名状态为所绑定的声明提供完整的外部 BUFF 列表，并可按字段覆盖角色与武器效果。空列表表示该状态无外部 BUFF，显式的零值和关闭值保留。
- 条目只保留这套手法声明的技能参数、附魔、求值方式、次数、权重、BUFF 参数、手填来源面板、状态绑定和逐段效果参数。生成器仅在存在逐段武器效果覆盖时记录用于还原编辑的武器标识。角色养成、武器养成、敌人面板、基础 BUFF 和候选圣遗物由实际计算提供。
- 已有 DSL 的伤害、属性与表达式能力、各入口的目标计算及配装筛选约束沿用现有实现。计算器的「配装目标 → 已保存手法」列出当前本地账户中所选角色的条目。选中后将当时的源码作为配装目标，沿用计算器当前条件，保存预设时也保留这份源码。

### 本地导入与导出（3.6）

- 导出需带上识别所属角色、恢复源码所需的信息。有生成器配置的条目应能按原配置再次打开，命名状态、BUFF 及其来源配置和适用的手法条件应随交换文件往返。已有手写 DSL 源码按原文本保留。
- 用另一份合成本地数据环境导入同一交换文件，应能识别角色并在对应列表找到该条目。文件内容限定为 DSL 条目及其所需配置。账号、UID、凭据、库存、完整角色预设和 Debug 数据不在交换范围内。
- 4.2 已确认交换文件为 DSL 管理页导出的版本化 JSON。导入先核对格式、版本、角色归属和条目数据，失败时显示具体原因。每次成功导入创建新条目，同名条目各自保留。

### 数据与计算验收

| 场景 | 通过条件 |
| --- | --- |
| 两个角色各有多个条目 | 保存、编辑、删除及重新打开都只影响目标条目。切换角色后显示对应的条目，现有角色预设仍可使用。 |
| 同一技能对应两个命名状态 | 使用合成装备分别设置不同 BUFF、技能参数或效果状态。保存并重新打开后源码和生成器配置保持一致，两段结果与独立计算一致。基础声明与无外部 BUFF 状态单独核对，显式零值和关闭值保留。 |
| 生成器条目导出后导入 | 源码、角色、命名状态、BUFF 参数及有效的生成器配置完成往返。在相同基础输入下，逐段结果和总分一致。 |
| 手写条目与失败路径 | 手写源码导出并导入后内容一致。无效文件或失败的导入不留下半条记录，冲突不会静默覆盖。 |

## 实施与验收依据

按当前 [MONA-DSL 逐段状态规格](../dsl-segment-states/spec.md) 核对基础设置、状态覆盖、源码还原和计算结果。结合现有的 [公式与属性作用域](../../dev/formula-scope.md) 验证 BUFF 的计算语义。使用合成数据从 DSL 管理页面完成保存、重新打开、导出及导入流程，再用现有 DSL 计算入口比较同一输入下的逐段结果和总分。

## 在线分享与分发

- 「在线分享」从手法卡片发起，沿用 [分享链接规格](../share-links/spec.md#dsl-和角色预设分享) 中的 MONA-DSL 快照、有效期和撤销语义。
- 管理者通过在线服务的 `/admin/dsl` 选角色、添加或替换版本化 JSON、查看源码和暂存删除。按角色发布整组手法。服务端校验文档、角色和版本，遇到发布冲突时保留草稿。
- 玩家选中角色后点「在线更新」，从当前配置的在线服务获取该角色的版本。成功后整组替换同一服务、同一角色的在线手法。原有本地手法保留，已下载的在线手法继续可用于配装。
