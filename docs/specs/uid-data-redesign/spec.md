# UID 数据页重做

Status: done

2026-11-15 与开发者对齐：布局选「左栏操作 + 右侧角色」。左栏放账号登录与同步、手机互传、导入记录；右侧大区域放已保存的角色（UID 切换、元素筛选、角色卡片网格），点卡片进计算器。手机上角色排在最前，其余在下方。

动手前先读根目录 `AGENTS.md`。颜色读 `src/styles/content-theme.css` 的 `--cx-*`。

## Problem Statement

- 整页是一条长列，账号管理、角色、导出导入、导入记录挤在一起，没有分块。
- 最常用的「已保存的角色」夹在中间，是一行一行的列表。
- 配色是旧的蓝色和 Element Plus 默认样式。

## Solution

1. 页面做成圆角内容块；内容分四张卡片：Cookie 账号管理、已保存的角色、手机互传、导入记录。
2. 按导入组件自身宽度排版（容器查询，900px 为界）：宽时左栏三张、右侧角色卡片跨满高度；窄时角色在最前。
3. 角色：UID 用胶囊切换（选中金色），元素筛选改成带图标的胶囊按钮，角色做成卡片网格（立绘、名字、元素、命座胶囊、武器类型、武器、圣遗物套装、天赋）。
4. 账号、导入记录用浅一层底色的圆角行；按钮改成圆角，主按钮金色。

## Implementation Decisions

1. **组件共用**：`MiyousheImport` 同时用在 UID 数据页和计算器的「导入我的角色」弹窗，`MiyousheCharacterPicker` 还用在「米游社 · 选择角色」弹窗。排版按组件自身宽度切换，不加属性；两个弹窗加 `custom-class="cx-scope"` 取得配色。弹窗里各块去掉卡片底色（弹窗本身就是卡片底色），这两条规则要带弹窗祖先选择器，写在非 scoped 的 `<style>` 里（scoped 里的 `:global(.el-dialog) .x` 会被编译成单独的 `.el-dialog`）。
2. **逻辑不动**：登录、同步、验证、Cookie 管理、导出导入、撤销导入的脚本原样保留，只改模板和样式。
3. **元素筛选**：`el-tabs` 换成按钮组（`aria-pressed`），文字和图标不变。
4. **手机旧规则**：`src/styles/mobile.scss` 里给旧角色行加的 `padding-left: 88px` 和行内边距会把卡片挤歪，删掉；其余手机规则保留。

## 文案

- 新增卡片标题「手机互传」（侧栏原有「UID 数据 / 手机互传」）。其余文字沿用原文案；导入记录的空状态由 `el-empty` 换成同样文字「暂无导入记录」。

## Testing Decisions

- 没有测试引用这两个组件。
- 浏览器实测：桌面深色和浅色、手机宽度、计算器「导入我的角色」弹窗；用合成数据（5 个合成计算预设、合成 UID 角色、导入记录，账号列表和同步结果只放在组件状态里），看完删除并恢复为空，刷新后确认为 0。

## Out of Scope
