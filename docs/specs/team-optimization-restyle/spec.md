# 多人优化页换配色

Status: done

2026-11-15 开发者要求重做多人优化页。这一页本来就是卡片式布局，又是四人轴的专用界面，本次只换成夜空配色，不改结构、交互和文案。

## 做了什么

- 新增 `src/pages/TeamOptimizationPage/team-dps-night.css`，在 `team-dps-theme.css` 之后加载，用 `html[data-color-mode]` 前缀压过组件里 scoped 的原色值。
- 页面根和 7 个弹窗加 `cx-scope`，颜色读 `src/styles/content-theme.css` 的 `--cx-*`。
- 底色和卡片换成内容区配色，去掉卡片细边框和阴影；青绿、蓝色强调（选中角色、命座、轴长、滑块、角色小标签、标题图标）换成金色；表格、数字输入、选角弹窗跟着换色。

## 验证

- 2026-11-15 内置浏览器 1440 宽：深色（通用设置、队伍配置、装备配置、联合优化）、浅色（计算主界面、管理计算配置编辑器）截图，显示正常。测试时新建的一条动作轴已用页面的删除按钮删掉，配置库回到空。没有看手机宽度，也没有跑四人轴计算。
