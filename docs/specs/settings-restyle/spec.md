# 设置页换样式

Status: done

2026-11-15 开发者要求按页重做时做到这一页。设置项不变，只换成夜空风格。颜色读 `src/styles/content-theme.css` 的 `--cx-*`。

## Solution

1. 页面做成圆角内容块，标题用路由已有的「设置」。
2. 外观：三张带缩略图的选项（浅色 / 深色 / 跟随系统），缩略图画的是侧栏、内容卡和金色胶囊；选中的一张金色描边。用 `role="radiogroup"` / `role="radio"` 和 `aria-checked`。
3. 其余设置排成一张卡片里的几行：左边名称（使用统计带原有说明），右边控件：语言下拉、使用统计开关、「清空本地存储」（红字胶囊按钮，仍先弹出原有确认）。

## Implementation Decisions

- 设置逻辑不变：`setColorMode`、`setLocale`、使用统计开关、清空存储都沿用原函数。
- 缩略图的颜色固定表示两种模式，不随当前模式变化，写成带默认值的 `var()`，避开构建时配色插件对字面颜色的改写。
- 文字全部沿用原有 i18n。

## Testing Decisions

- 浏览器实测：桌面深色、浅色手机宽度；点浅色再点回深色（`data-color-mode` 和 `aria-checked` 跟着变，最后恢复为深色）；点「清空本地存储」确认框弹出后点取消，本地存储未被清空。
