# 05: 补丁检查与下载

**What to build:** 客户端启动时查补丁清单，之后定时再查。有更新就下载、校验、放进覆盖层，下次启动生效。

**Blocked by:** 01, 04

**Status:** ready-for-agent

清单地址已定（2026-11-20）：写成一个常量，开发和测试用本地假服务，在线服务部署后只换这个常量；真实地址由开发者部署后提供。校验直接用 `server/patch-package.mjs` 的 `verifyPatchPackage`，公钥来自构建配置。

规格见 `docs/specs/content-patch/spec.md`。

- [ ] 启动时查一次清单，之后每隔几小时查一次，或玩家打开计算页时查一次。用 `ETag` 或 `If-Modified-Since`，没变化时只取回 304
- [ ] 清单里的补丁号不高于本机、或基础版本不适用时什么都不下载
- [ ] 下载走现有的下载线路（GitHub、CNB、镜像）选择方式，复用 `update-sources.mjs`，不另写一套
- [ ] 下载完成后用任务 01 的模块校验，通过后交给任务 04 的存储，当前这次运行不换数据，下次启动生效
- [ ] 查不到、下载失败、校验失败都不打扰玩家，保持现有补丁继续用，原因和阶段记进 Debug，下次再试
- [ ] 玩家可以在设置里关闭自动补丁，关闭后不再查清单（沿用 `release-update.mjs` 里自动检查开关的做法）
- [ ] 测试：用本地假的清单服务覆盖无更新、有更新、下载中断、签名错误、哈希错误、基础版本不适用、离线
- [ ] 验证：跑新增测试；报告里说明没有连真实服务
