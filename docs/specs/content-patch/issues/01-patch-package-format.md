# 01: 补丁包格式与校验

**What to build:** 一个纯逻辑模块，定义补丁清单的格式，并能校验一个补丁包：清单签名、每个文件的 sha256、路径是否在登记表内、基础版本是否适用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-human

需要开发者先定：签名私钥由谁保管（见规格「待开发者决定」第 2 条）。格式和校验本身可以先做，用测试密钥对跑测试。

规格见 `docs/specs/content-patch/spec.md` 的「补丁包格式」。

- [ ] 新建补丁校验模块，不依赖 Vue、浏览器专有 API 或 Node 专有 API，桌面页面、Worker、Node 测试和打包工具都能直接导入。签名和哈希用 WebCrypto（浏览器和 Node 都有）
- [ ] 清单字段：补丁号、适用基础版本范围、文件列表（路径、sha256、大小）、创建时间
- [ ] 校验顺序：先验清单签名，再逐个文件核对大小和 sha256，再核对路径在登记表内、基础版本适用
- [ ] 登记表（允许被补丁替换的路径）独立成一份清单，初始内容见任务 03；本任务先用测试用的小登记表
- [ ] 公钥写成常量，由构建配置注入，不写私钥；测试用的密钥对放在测试夹具里，不要用真实密钥
- [ ] 校验失败的错误带阶段（签名、哈希、路径、版本）和原因，不吞异常
- [ ] 测试：正常包通过；清单被改一个字节签名失败；文件被改哈希失败；路径含 `..` 或不在登记表内被拒；基础版本不在范围内被拒；缺文件、多文件被拒
- [ ] 验证：只跑新增的测试文件
