# 06: 补丁号显示、Debug 与使用统计

**What to build:** 让玩家和开发者都能看出当前生效的是哪个补丁：设置里显示补丁号，Debug 导出写明补丁号和各文件哈希，使用统计能区分补丁号。

**Blocked by:** 04

**Status:** ready-for-human

需要开发者先定：使用统计里补丁号是并进 `version` 还是另加字段（规格「待开发者决定」第 4 条），以及设置和账户页新增文字的文案。界面新增文案要先交开发者确认。

- [ ] 设置页或账户管理与同步页显示当前补丁号和自动补丁开关；文案先交开发者确认
- [ ] Debug 导出新增补丁信息：补丁号、基础版本、覆盖的文件和哈希、最近一次检查或下载失败的阶段和原因
- [ ] 使用统计：按开发者定的方案处理。并进 `version` 时只需让上报读到生效后的版本号；另加字段时要改客户端上报、服务端表和 `/admin/stats` 的筛选，服务端表结构改动要先向开发者说明
- [ ] 补丁没有生效（没有覆盖层）时，显示和上报都和现在一致，不多出任何字段
- [ ] 验证：跑 Debug 导出和使用统计相关的现有测试加新增用例
