# 04: 覆盖层存储与加载

**What to build:** 把校验通过的补丁存进用户数据目录，页面和 Worker 在启动计算内核之前读到它。支持回滚。

**Blocked by:** 01, 03

**Status:** ready-for-agent

规格见 `docs/specs/content-patch/spec.md` 的「Solution」。本任务先做 Windows 桌面，Android 见任务 08。

- [ ] 本机服务（`server/local.mjs`）新增读取覆盖层的接口，覆盖层存放在 `MONA_DATA_DIR` 下的专用子目录。不动用户的账号、预设和库存数据，也不改已保存数据的位置
- [ ] 写入是原子的：先写临时目录，校验通过后一次改名生效；写入中途断电不会留下半个补丁
- [ ] 页面启动时先取覆盖层，再初始化计算内核；取不到或没有覆盖层时按原数据运行，并把原因记进 Debug，不弹错
- [ ] 四人轴 Worker 和其他 Worker 拿到同一份覆盖数据（由页面启动时传入或 Worker 自己通过同一个接口读取，保证与页面一致）
- [ ] 已生效的补丁文件在每次启动时重新校验哈希，被改坏的覆盖层按「没有覆盖层」处理并记录原因
- [ ] 回滚：删除覆盖层目录即可；提供一个只在本机服务内调用的回滚入口
- [ ] 基础版本升级后，适用范围外的旧补丁在启动时自动作废
- [ ] 验证：Node 测试覆盖原子写入、损坏覆盖层、版本作废；浏览器里实际启动一次确认读到补丁数据（要说明有没有真的开浏览器）
