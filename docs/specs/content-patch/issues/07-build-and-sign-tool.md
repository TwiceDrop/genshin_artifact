# 07: 补丁打包与签名工具

**What to build:** 一条命令，从仓库里已改的数据文件生成补丁包并签名，供开发者发布。

**Blocked by:** 01

**Status:** ready-for-human

需要开发者先定：签名私钥放在哪里（规格「待开发者决定」第 2 条）。私钥不能提交进仓库，工具只从环境变量或本机文件读取。

- [ ] 在 `beta-tools/` 下新增脚本：输入基础版本和要打进补丁的数据文件，输出补丁包目录（清单、数据文件、签名）
- [ ] 补丁号自动在上一个补丁号上加一，也允许手动指定；补丁号写成 `7.2.05EA.01` 这种形式
- [ ] 只允许打登记表内的文件，打了表外的文件时直接报错，不跳过
- [ ] 生成后立即用任务 01 的校验模块自检一次，不通过就不输出
- [ ] 不接发布：工具只生成本地文件，不上传、不推送、不创建 Release
- [ ] 提供生成测试密钥对的子命令，输出的私钥只写到用户指定的位置
- [ ] 验证：用测试密钥打一个补丁，再用任务 01 的模块校验通过
