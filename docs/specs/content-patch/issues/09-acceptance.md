# 09: 实机验收

**What to build:** 用真实安装包把补丁通道从发布到生效走一遍，确认玩家实际看到的行为。

**Blocked by:** 03, 04, 05, 06, 07

**Status:** ready-for-human

需要开发者提供测试用的签名密钥、补丁清单地址和安装包。测试产物放在 `.cache/test/content-patch/`，用完删除。

- [ ] 用工具打一个把某把武器数值改掉的补丁，发布到测试地址
- [ ] 安装包启动：下载补丁，下次启动后伤害结果变化，设置里显示补丁号
- [ ] 补丁被改坏一个字节：被拒绝，软件照常使用原数据，Debug 里有失败原因
- [ ] 基础版本升级到新版本：旧补丁自动作废
- [ ] 回滚：删除覆盖层后恢复原始数据
- [ ] 离线启动：软件照常使用
- [ ] 使用统计：能看到补丁号（按任务 06 定的方案）
- [ ] 实测通过前不对外发布补丁，也不发 Release
