## Problem Statement

- 新增按钮只有一个「+」，紧挨着红色的「清空」，容易误点；导入、导出、推荐挤在一排小按钮里。
- 部位标签只有很淡的图标，没有文字和件数。
- 卡片小、字号约 12px，锁定 / 删除 / 编辑三个小图标难点；页面右侧大片空白。
- 一个部位的圣遗物全部一次性渲染，仓库上千件时会卡。

## Solution

1. **工具栏**：标题「圣遗物」和「共 N 件」；右侧「导入」「导出 ▾」（mona JSON、分享链接 / 保存分享文件）、「更多 ▾」（全部解锁、推荐、清空仓库）、金色主按钮「＋ 新增圣遗物」。清空仍需确认。
2. **部位切换**：一排带文字和件数的按钮：全部、生之花、死之羽、时之沙、空之杯、理之冠。
3. **筛选栏**：套装（多选）、主词条（多选）、评分角色、只看 16 级以上。评分角色使用和 DSL 管理相同的头像网格，支持元素筛选和名称搜索，五星在四星前。选中角色按喵喵评分从高到低排，清除选择恢复原顺序。
4. **卡片网格**：每张卡片显示图标和等级、套装名和部位、主词条（大字）、四条副词条（暴击、暴伤用金色）、选了评分角色时显示评分、已锁定时显示锁图标。评分角色旁的显示设置可分别隐藏花和羽毛卡片的主词条、隐藏卡片的喵喵评分。隐藏评分后依然按所选角色的评分排序。点卡片打开详情抽屉。
5. **分页**：每页 60 件，切换部位或改筛选后回到第 1 页。
6. **详情抽屉**：大图标、套装名、部位、星级、锁定状态、主词条、副词条、评分（选了角色时）与「评分详情」入口、二件套和四件套效果、「编辑」「锁定 / 解锁」「删除」。点「编辑」在同一个抽屉里换成现有的编辑表单，确认或取消后回到详情。

## Implementation Decisions

1. **抽屉和配色共用**：计算器的抽屉外壳 `CalcDrawer` 和配色 `calculator-theme.css` 是第二处使用，移到共用位置：抽屉改名 `SideDrawer`，放在 `src/components/misc/`；配色移到 `src/styles/content-theme.css` 全局引入，变量挂在 `.cx-scope` 上（计算器内容区、圣遗物页、抽屉都加这个 class）。变量名不变（`--cx-*`）。
2. **卡片组件**：新建 `ArtifactCard.vue`（圣遗物页目录下），只收一件圣遗物和可选评分，发出点击事件；词条名称和数值格式沿用 `ArtifactDisplay` 用的 `displayedTag`。旧的 `ArtifactDisplay` 计算器抽屉等处还在用，不改。
3. **锁图标**：用 Element Plus 图标集的锁（`ep:lock`），放在金色描边的小圆底里，不用 emoji。
4. **全部部位**：「全部」时按部位顺序（花、羽、沙、杯、冠）排列，件数为所有部位之和。
5. **删除**：沿用现在的行为，点删除直接删除，不加确认（加确认属于新拦截，先不做）。
6. **编辑与新增**：编辑沿用 `EditArtifact` 组件和 `handleConfirmEdit`，放进详情抽屉；新增仍用 `AddArtifactDialog`。原来独立的编辑抽屉删掉。
7. **推荐、分享、导入**：推荐抽屉、分享弹窗、导入弹窗内容不变，只改入口位置。
8. **手机**：工具栏只留标题和「＋ 新增」，其余收进「更多」；部位按钮横向滑动；卡片单列或两列；抽屉从底部升起。
