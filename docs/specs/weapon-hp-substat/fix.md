# 讨龙英杰谭生命副词条修正

90 级讨龙英杰谭的生命副词条应为 35.2%，原始发布内核和扩展内核的 HP77 成长表均误填为 41.3%。修正共用表的 90 级锚点，保持 80 级 32.1% 和 HP90 系列 41.3% 不变。使用同一 HP77 表的铁影阔剑同步受影响。

## 实现

- Rust 的 HP77 成长表改为 0.352，供后续扩展内核编译使用。
- 原始发布 WASM 保留原样；效果桥接构建脚本校正派生内核的 HP77 表。
- 现有的效果桥接内核、扩展内核及两者的带进度版本做相同的定点数据修正，没有全量重编译扩展内核。
- 修正脚本先匹配全部八个旧锚点且要求唯一匹配，然后只替换最后一个 f64 值；四个产物均仅改变该数值内的 7 个字节。
