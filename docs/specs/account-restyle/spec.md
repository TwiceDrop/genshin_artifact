# 账号页换样式

Status: done

2026-11-15 开发者要求按页重做时做到这一页。功能不变，只换成夜空风格。颜色读 `src/styles/content-theme.css` 的 `--cx-*`。

## Solution

1. 页面做成圆角内容块，标题用路由已有的「账号」，右侧金色胶囊「＋ 添加账号」。
2. 账号做成卡片网格：圆形首字母头像、可点击改名的名称（`ClickEditLabel`，只有这一页在用，用 `:deep` 换输入框颜色和下划线）、右侧操作。
3. 当前账号：金色描边、金色头像、金色勾选图标，并带 `aria-current`；不加新文字。其他账号右侧是删除按钮，仍先弹出原有确认。点其他账号的卡片切换账号，和原来一样。

## Implementation Decisions

- 脚本逻辑不变（添加、切换、改名、删除、注释掉的同步代码都保留）。
- 图标在模板里写 `<icon-ep-x>` 时必须在脚本里显式 `import IconEpX from "~icons/ep/x"`；不引入时组件自动注册只认 `<i-ep-x>`，否则渲染成空标签。

## Testing Decisions

- 用 `@vue/compiler-sfc` 编译，没有模板错误、没有未解析的图标标签。
- 浏览器实测：桌面深色、浅色手机宽度；点「添加账号」新建一个测试账号看两张卡片，再用删除按钮和确认框删掉它，只剩原来的 default。
