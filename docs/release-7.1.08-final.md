# 莫娜占卜铺 7.1.08

本次发布 Windows 64 位 EXE 安装包、附带 Node.js 的 ZIP 便携包和 Android APK。Windows 解压后可直接运行 `启动7.1.08.exe`；Android 沿用 7.1.07 的包名和签名，可覆盖安装。保留既有访问地址和本地存档。

## 44 项修复

1. 修复配装 Worker 的模块加载错误，解决 `Cannot use import statement outside a module` 导致的计算失败。
2. 修复 Worker 失败时无有效结果或持续等待的问题，保留具体错误阶段，并正确清理计时器、监听器和 Worker。
3. 补齐晨星与月的晓歌、天之美赐、影中沉凝的幻灭等扩展效果的注册，使公共计算入口实际消费对应效果。
4. 修复直接星扩散攻击条件和风元素暴击／暴伤作用域，包括珐露珊六命及相关套装效果。
5. 修复莫娜、神里绫华等角色米游社导入的三个主动天赋对应错误。按技能名称匹配，兼容普攻名称前缀、标点差异、顺序变化及额外冲刺技能；角色摘要与计算预设共用结果，避免重复增加命座等级。
6. 修复部分 7.0／7.1 角色配装计算出现 `Unreachable` 的属性容量问题，覆盖沃雅妮莎、薇斯纳及冰旅行者相关扩展属性路径。
7. 修复自定义 MONA-DSL 读取错误输入参数的问题，使计算环境和作用域 BUFF 正确传入。
8. 修复桑多涅配装优化提前读取当前装备、导致未配置当前装备时失败的问题，候选装备独立计算。
9. 修复桑多涅星扩散及瑞希定额 DSL 的空装备／技能上下文，候选装备中的攻击转换随面板重新计算。
10. 修复沃雅妮莎支援路径错误过滤原有直接星／月伤害结果的问题，保留角色技能、天赋和命座自身造成的直伤。
11. 修复沃雅妮莎普通模式水／冰支援的元素作用域，避免泛化至物理等伤害，并解除错误的仅丝柯克目标限制。
12. 修复沃雅妮莎爆发歌声倍率，将其作用于普通伤害本体的独立乘区，避免错误放大后加定额。
13. 修复新增武器各等级、突破状态的基础攻击与副属性，配装候选按实际武器白值计算百分比属性。
14. 修复星剑效果对冰旅行者的支持及部分覆盖率，避免漏算或重复计入相关被动。
15. 修复白湖霜翎的三层／部分覆盖效果，补齐攻击及直接星超导、直接星扩散的专属暴伤。
16. 修复月结晶相关武器部分覆盖率的消费，使对应增益作用于直接月结晶伤害。
17. 修复月感电武器效果误写入月绽放属性槽的问题，恢复正确月感电通道。
18. 修复织夜之鉴不同状态的队伍反应增益与装备／队友重复来源处理，停用的队友来源不再遮蔽当前装备效果。
19. 修复真理之匣效果重叠计算，按显式重叠比例分别计算精通和暴伤，不再猜测重叠时间。
20. 补齐夜曲之帷月曜暴伤扩展属性的实际消费。
21. 修复普通伤害减防上限，按保留计算路径的 90% 上限处理。
22. 修复圣遗物配置参数的别名及缺省字段，使 `artifact_config`／`artifacts_config` 在公共接口正确传入内核。
23. 修复自定义敌人等级及各元素抗性在原生、扩展、配装优化和词条收益中的一致性。
24. 修复停用 BUFF 仍参与校验或计算的问题，在公共入口统一排除 `active: false` 等停用项。
25. 修复零基准伤害导致收益为无穷大的问题，保留具体错误，不用伪造的零收益掩盖原因。
26. 修复伤害明细和收益误选隐藏伤害分支的问题，按当前保留且实际显示的直伤分支计算。
27. 修复明细重算与主结果的公式差异，统一伤害本体、后加定额和最终乘区顺序。
28. 移除无关的零值直接月感电占位行，避免将没有产生的伤害显示为已计算结果。
29. 修复武器元数据字符串进入面板数值汇总的问题。
30. 修复面板统计、试算及配装对比中的相关异常处理，保留具体错误，避免无效预设和零分母产生误导结果。
31. 修复 Debug 导出文件名硬编码旧版本的问题，使用当前软件版本。
32. 修复 Android 导出 UID／圣遗物数据点击系统“保存”后崩溃且不生成文件的问题。大载荷暂存后仅在保存状态中保留小标识，目标 URI 实际打开、写入并关闭成功后才报告保存完成；取消或失败正确处理暂存文件。验证包含真实系统保存、文件完整回读和重新导入。
33. 补齐沃雅妮莎立绘，移除计算页错误隐藏条件，并检查其他角色图片引用。
34. 补齐漩流颂歌及相关 BUFF、配装目标图片，替换缺失占位资源，并检查其他武器图片引用。
35. 补齐沃雅妮莎、奇偶的评分基础数据和七元素杯权重，元素伤害主词条按原生元素匹配。
36. 修复薇斯纳评分基础数值及两种模式，修正替换详情和重复排名。
37. 对齐固定喵喵评分来源的角色权重与八项条件规则，补齐胡桃、行秋、神里绫华、香菱等评分逻辑；修复并列权重选择理想主词条的次序。六命万叶样例由 37.0 修正为 35.5 分，雷电将军默认样例由 33.6 修正为 32.0 分。
38. 修复冰套简称导致甘雨冻结条件评分规则未生效的问题。
39. 修复迪希雅评分查询多部位主词条的条件，使生命等分支按完整配装判断。
40. 接通 `StellarSwirlDamageMultiplier` 的直接星扩散本体倍率，覆盖瑞希、奥黛塔、桑多涅、冰旅行者的旧角色路径；倍率不错误放大后加定额，零本体倍率仍保留定额伤害。
41. 补齐七七六命定额在奥黛塔五条、冰旅行者三条直接星扩散 DSL 中的接入，候选面板和双暴动态重算；冰旅行者寒辉只作用于本体。
42. 补齐沃雅妮莎星扩散模式 A4／C2／C6 对相关旧角色的支援，将专属定额、暴伤、擢升接入单次、DSL、优化和收益的实际消费路径。
43. 修复薇斯纳适配层丢弃沃雅妮莎普通模式 C2 的问题，水／冰附魔普攻正确获得元素暴伤。已复现样例的暴击伤害由 308.1379455 修正为 410.850594。
44. 修复编译后的通用星烁增伤／擢升在旧原生直接星超导路径失去通用作用域的问题。只按明确的通用来源恢复效果，专属星扩散属性保持专属；桑多涅样例恢复至 7700.515374，与原始 BUFF 输入一致。

Astra 已完成此前 01–44 清单审查，唯一遗留的评分并列次序问题已修复。本次沿用这些修复证据，重点核对跨版本数据兼容和最终打包结果。
