# 莫娜占卜铺 7.1.10

发布 Windows 64 位 EXE 安装包、附带 Node.js 的 ZIP 便携包及 Android APK。Windows ZIP 解压后运行 `启动7.1.10.exe`；Android 沿用原包名和升级签名。启动器显示版本为 7.1.10，数字版本为 7.1.10.0。

## 配装、武器与 BUFF

1. “过滤圣遗物组”增加名称搜索和中文拼音／名称排序，便于查找收藏夹及圣遗物组。
2. 完整圣遗物组可显示与五槽配装准确匹配的角色头像，支持多角色匹配。修复空组、少于五件的旧组及含已删除装备的组误显示头像的问题；仓库删除装备后头像更新。
3. 搜索、清空搜索及组数据刷新保留勾选；组过滤保留当前角色已选的五件装备，锁定、主词条、他人穿戴及队友占用约束继续生效。
4. 接入银釭（Silver Light）的正式等级／突破／精炼数据、图标和有效层参数。每层精通按精炼为 52／65／78／91／104，最多 2 层；当前有效层参与面板、单次、DSL、单人配装和词条收益计算。
5. “选择 BUFF”五个分类统一为添加后保持窗口打开，可连续选择；保留搜索、页签、角色配置、其他分类默认配置及去重。

## 旅行者修复

6. 修复女旅行者同步／导入时报“未知角色：旅行者”、无法在计算器应用的问题。补齐荧的七元素目录、中文／英文名称、女性图片、草／冰专属目标及冰 BUFF 来源；保留原始角色 ID 10000007、女性身份与元素，不把荧保存为空。
7. 按正式数据处理男女第二段重击倍率差异，同步用于单次伤害明细、DSL、配装候选和词条收益，保持定额加值正确。冰默认目标按原发布内核的技能权重计算，水荧补齐第二段重击选项；DSL 合法对象复制及变量赋值保持原语义。
8. 已保存的女旅行者失败快照可通过重新同步／重新导入恢复预设和清除错误；保留原身份键，重复导入复用圣遗物与同一预设，保留已保存的计算参数。

## 界面清理

9. 移除仓库的 YAS WebUI 扫描按钮、连接弹窗和专用实现，保留圣遗物文件导入功能。
10. 移除导出工具页的「天目」Amenoma 条目，在首页“开源地址”区域加入 GOODScanner 项目链接。
11. 移除页脚备案号。
12. 移除“圣遗物潜力”“最佳圣遗物”“莫娜数据库”三个独立功能的菜单、路由及专用页面／代码；首页保留功能卡片调整为三列。多人优化入口保留，公共计算、角色／武器／圣遗物数据及评分继续使用。

7.1.09 及更早版本已完成的功能和修复继续保留，历史见 [7.1.09 更新说明](https://github.com/TwiceDrop/genshin_artifact/releases/tag/v7.1.09)。HoYoLAB 海外同步／扫码和按面板属性筛选排序仍处于调研完成、尚未实现的状态；库存原生静态推荐权重继续按用户要求暂缓。多人优化实验在独立 Beta 维护，不作为本版新增功能。
