# 莫娜占卜铺 7.1.11

提供 Windows 64 位 EXE 安装包、附带 Node.js 的 ZIP 便携包及两种 Android APK。Windows 启动器为“启动7.1.11.exe”，显示版本7.1.11，文件／程序集版本7.1.11.0；旧Element Plus APK沿用原包名com.mona.artifact.local及升级签名；新UI测试APK使用独立包名com.mona.artifact.local.mobiletest，可并存安装。两版versionCode为70111、versionName为7.1.11，数据各自保存，可通过文件互传。

## 本版更新

1. 圣遗物仓库新增角色喵喵评分排序：支持搜索和清空角色，按当前部位单件评分从高到低排列；可与套装、主词条和等级筛选共同使用，同分保留原顺序，清空恢复原顺序。卡片显示分数／等级，详情默认跟随所选评分角色；旅行者七元素及薇斯纳普通／星扩散模式均使用已有内置规则，编辑装备后重新评分。
2. 修复 Windows 下载后点击安装、旧程序退出却未启动安装的问题。独立临时Node进程承载PowerShell，收到脚本实际接管确认后才关闭旧服务；承载进程不锁住原Node运行文件，EXE／ZIP更新继续使用原目录和端口。启动失败保留可安装状态与具体错误，新增本次安装进程日志。
3. Android更新返回系统实际等待／暂停状态和原因，显示等待系统开始、等待重试、等待网络或等待Wi-Fi等状态；等待和暂停期间继续轮询，可取消下载，保留下载失败代码与完整字节检查。
4. 修复取消下载后、迟到的旧进度回读重新覆盖“已取消”的时序问题，避免旧结果继续触发安装。
5. Android同时提供旧Element Plus界面正式APK和独立的新UI测试APK。新UI使用此前已完成的shadcn-vue布局：手机导航和底部入口、安全区域、单列布局、Sheet弹窗、可搜索选项、卡片式表格、树形筛选和数值控件；保持原数据模型、事件、存储和计算接口。桌面及旧UI APK继续使用原Element Plus界面；两版软件内更新按各自UI选择APK，避免串版。本项手机源码此前未随7.1.10正式APK发布。
6. 新增[使用文档](https://github.com/TwiceDrop/genshin_artifact/blob/main/docs/user-guide-7.1.11.md)，覆盖单次伤害、自动配装、BUFF来源、筛选与锁定、装备对比、评分、词条收益、预设、DSL和Debug，附19张合成数据操作截图。

7. 修复新UI分类栏不能用鼠标按住横向拖动的问题，公共分类栏保留触屏原生横向滚动；BUFF各分类与原有点击切换继续使用。

## 升级及当前边界

- 已安装旧版仍运行旧更新器。Windows旧客户端首次取得本次更新修复需先手动下载EXE覆盖安装，或退出后使用新版ZIP；无需删除本地数据。后续版本再使用新更新器。
- Android等待／暂停信息丢失已经修复；此前用户手机一直0%的具体系统原因仍需新版本实际状态确认。不能把此项写成所有手机的下载阻塞均已解决。
- 薇斯纳快捷目标限制仍保留；哥伦比娅配装超时按用户要求暂缓，尚未实施生产计算修复。HoYoLAB海外同步／扫码、面板属性目标／筛选／排序尚未实现，库存静态推荐权重继续暂缓；多人优化实验继续由独立Beta维护。
- 7.1.10及更早正式版已完成的功能继续保留，历史见[7.1.10更新说明](https://github.com/TwiceDrop/genshin_artifact/releases/tag/v7.1.10)。
