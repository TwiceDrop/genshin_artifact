# 莫娜占卜铺 7.2.03

本版整合单次伤害、单人配装和四人固定轴 DPS，提供 Windows 安装器、ZIP 便携版、Element Plus 与新 UI 测试版两种 Android APK。

## 新增与改进

- **面板配装**：支持攻击、生命、防御、精通、充能、暴击率和暴击伤害目标，搭配属性上下限筛选结果。
- **单次计算页面**：桌面改为浅色两列布局，角色、武器、圣遗物和伤害配置集中在左侧，实时面板在右侧；顶部可展开目标函数，附魔移至敌人设置。
- **BUFF 管理**：按角色、武器、圣遗物分类，有自定义项时增加第四列；长列表统一滚动，保留停用、编辑及连续添加。
- **星／月反应基础区自定义**：可为星超导、星扩散、月感电、月结晶和月绽放设置基础提升百分比，支持多条叠加、停用及预设保存。
- **配装结果对比**：清楚展示候选装备的实际变化、目标收益与充能门槛，DSL 组合和单段伤害分别比较。
- **后台计算与历史**：单人和多人计算可进入后台，按账号保存历史；支持角色、武器和多人轴文件筛选，查看装备、恢复配置及取消任务。
- **四人固定轴扩展**：新增米提亚、瓦列里、砂糖、薇斯纳和珐露珊，当前共支持 15 位角色。补充共享元素附着、反应、资源、治疗、有限次数增益和装备事件，计算结果可查看逐事件明细。
- **词条收益曲线**：相同完整配置可复用结果，页面刷新保留缓存；本地程序重新启动或账号库存变化后失效，取消原 20 组缓存上限。
- **评分显示**：喵喵评分数字和评级按等级着色；修复词条浮点长尾，非百分比词条至多显示一位小数。

## 修复

- 米提亚默认目标和词条收益随无炉心、稳态、过载模式切换。
- 按正式服资料核对米提亚、瓦列里与相关专武，修复特殊重击初段和瓦列里弹幕附着间隔、信标到期刷新、炉心生成、重击中断及场地生成时机。
- 按实机计帧调整米提亚特殊重击后首星段为 0.5 秒、长按 E 命中延迟为 0.7 秒、Q 命中延迟为 2.2 秒；预览和计算使用相同时序。普通初段先于同刻首星段结算，避免六命增益反向影响已发生的伤害。
- 修复历史装备缺少仓库编号时点击“对比历史”导致白屏，以及锁定、历史待保存装备和结果展示相关问题。
- 改进复杂命座队伍的编译等待，修复高命沃雅妮莎倍率预览读取尚未结算治疗的问题。
