# 莫娜占卜铺 7.1.12

提供 Windows 64 位 EXE 安装器、附带 Node.js 的 ZIP 便携包、Android 旧 Element Plus UI APK 和独立的新 UI 测试 APK。CNB 与 GitHub 提供相同成品和对应源码。

## 新增功能与特性

1. 沃雅妮莎新增并默认选择“生命值上限最高”配装目标，保留原“终奏”目标及已有预设。
2. 新增 DSL 生成器：按当前角色选择技能、期望／暴击／非暴击、附魔、技能参数、次数及权重，生成组合目标用于单人配装；支持保存和恢复预设，覆盖本版 141 个角色的技能映射。
3. 直伤星扩散／星超导新增详细属性来源与可编辑乘区，支持逐来源勾选、修改和本地即时重算。
4. 配装计算展示搜索阶段、候选空间、实际评估次数、剩余分组、已用时间和预计剩余时间。
5. 新增完整结果弹窗，展示全部保留搭配的五件圣遗物、当前技能伤害及相关面板。
6. 搭配结果支持期望／暴击／非暴击升降序；多伤害分支可选择排序依据。
7. 支持点击或键盘确认选用搭配，精确更换五件装备并同步对比历史，不自动覆盖已保存预设。
8. 新增“取消计算”，停止搜索后保留原装备、已有结果与预设，支持再次计算；Debug 保留取消状态。
9. 移除单人配装原有的 600 秒自动终止限制。
10. 新增 CNB 独立更新源，支持 Windows 安装器／便携 ZIP 及两种 Android UI 各自的 APK。
11. 绿色“使用 CNB 下载（推荐）”作为默认下载入口，直接下载，不测速。
12. 下方灰色“使用其他下载源下载”打开独立选择框，点击后才展示 GitHub 与其他线路并测速。

## BUG 修复与性能优化

13. 优化属性图构建与固定模板复用。已测哥伦比娅 724 候选不限套装完整搜索从 374.26 秒降至 221.78 秒，耗时减少约 40.74%；最终 100 套装备、分数与排名完全一致。该数据为同设备、同输入对照，不代表所有设备的固定耗时。
14. 修复计算尾段预计剩余时间长期停在 1 秒：按当前搜索阶段近期速度估算，样本不足、停滞或估计过期时显示“估算中”。
15. 恢复蝶变、漩流颂歌、沃雅妮莎、薇斯纳、七七、桑多涅、柔风游弦等共 15 项武器／角色 BUFF 游戏原文描述。
16. 修复伤害明细中 ScarletProof2／4 等英文套装键，显示对应中文套装名称及件数。
17. 修复更新说明弹窗长行出框、窄屏换行及滚动异常，保留底部操作按钮。
18. 修复关闭第三方下载加速后漏查 CNB 新版本：查询不再受旧设置影响，先查 CNB，CNB 无更新或失败后再查 GitHub。

## 安装与升级

- Windows 安装器和 ZIP 均自带 Node.js；ZIP 解压后运行“启动7.1.12.exe”。启动器与安装器文件版本为 7.1.12.0。
- 旧 UI APK 保持包名 `com.mona.artifact.local`，新 UI 测试 APK 保持独立包名 `com.mona.artifact.local.mobiletest`；两者沿用原升级签名，versionCode 为 70112、versionName 为 7.1.12。选择与已安装 UI 相同的 APK 覆盖升级，两种 UI 的数据各自保存。
- 正式 7.1.11 尚未包含本轮 CNB 默认入口，可通过 GitHub 检查更新或手动下载本版覆盖安装；升级后使用新的 CNB 优先流程。已有 CNB 测试包可手动覆盖为正式包。
- 版本升级保留原端口、应用身份与存档位置。CNB R2 已完成真实远程下载、隔离 Windows 覆盖和两种 Android UI 的合成存档保留验证，用户反馈 APK／EXE 实机安装成功；正式成品的本轮核对范围单独记录于发布核对文档。
