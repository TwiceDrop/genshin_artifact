# 莫娜占卜铺 V7.2.02

本版保留单次伤害、单人配装与 TeamDPS，新增国际服网页登录与角色导入，修复 BUFF 参数和基础乘区问题。

## 新增与改进

- UID 数据页分别提供“使用米游社登录”和“使用 HoYoLAB 登录”。米游社沿用扫码；HoYoLAB 使用官方网页，支持国际服绑定角色读取、角色养成／武器／已装备圣遗物同步，账号按平台区分。
- Windows HoYoLAB 登录保留官方弹窗和回调，修复卡在账号安全检查页的问题。用户已确认 Windows 真实登录和国际服同步成功。
- Android 接入 HoYoLAB 网页登录，支持弹窗回调、返回／取消、窗口清理及切换账号时旧请求隔离。合成流程和独立模拟器 WebView 验证通过，手机真实账号登录仍待实机验证。
- 米提亚队友 BUFF 拆成五个独立效果，分别处理祝礼、模式、命座和触发条件。
- 沃雅妮莎七项 BUFF 去除 23 个未参与计算的自定义参数，保留实际生效选项及旧配置读取。

## 修复

- 修复奥黛塔祝礼在扩展角色接口中星超导基础加成减半的问题：每 100 攻击力提升 0.7%，最高 14%；手动 BUFF、队友来源、DSL 与配装计算统一。奥黛塔自身及 TeamDPS 原有正确计算保持。
- 修复闲云 A4、卡齐娜 C4 的应用比例未参与计算。
- 修复手机新 UI 圣遗物套装图片尺寸异常。

## 下载与使用

提供 Windows x64 安装器、Windows ZIP 便携包、Android 原 UI APK、Android 新 UI APK。Windows 包自带 Node.js 和 HoYoLAB 登录宿主，登录窗口依赖系统 Microsoft Edge WebView2 Runtime。

两种 Android 包沿用各自原包名及升级签名；新 UI 仍为独立应用，可与原 UI 并存。更新前退出旧版，账号、库存、预设和轴继续使用原有本地保存规则。HoYoLAB 当前实现为网页登录，并非海外扫码。

本版未新增游戏版本角色或武器数据；保留 V7.2.01 的机制适配范围与已记录边界。
