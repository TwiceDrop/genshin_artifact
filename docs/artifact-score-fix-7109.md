# 圣遗物评分修复 — 7.1.09

日期：2026-10-06。此前核查见 [补丁核查记录](artifact-score-patch-review-7109.md)。

## 已修复

业务修改仅在 src/algorithms/artifact-score/vendor/miao.mjs：

- def 的专武、绝缘、西风修正共用于默认和具名流派；保留角色规则给出的初始权重，再应用上游全局修正。
- 删除玛薇卡的抢先返回分支，直接使用已存在的 rules/玛薇卡.mjs。精通低于 50 时攻击 85、精通 0，否则保留默认精通 85。
- 绝缘按 min(round(原充能权重+75),当前最高缩放权重) 计算，原充能为 0 时也能生效。
- 返回标题按角色名及 | 分隔的标签组合；最终算分顺序对齐上游 value*(1+factor)/2/limit*66。未新增产品说明；舍入项仅作实现对齐，不宣称发现了新的 0.1 分反例。

没有修改角色权重、固定评分模板、库存推荐、伤害内核或锁定操作。三个问题为既有评分缺陷。

## 四项定向验证

使用当前真实 createScoreEvaluator、scoreBuild、scoreDetails 和隔离执行的固定喵喵原始 ArtisMark／ArtisMarkCfg；合成词条及面板，无用户数据。原始函数与角色规则来源和输入详见此前核查记录。每个普通数值样例同时断言权重、标题、一位小数与单件明细相同，原始分数误差小于 1e-10。
