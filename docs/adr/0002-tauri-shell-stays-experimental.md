# Windows 正式发行继续用托盘启动器，Tauri 2 封装保留为实验形态

Windows 上有两种封装：正式发行用的「托盘启动器加默认浏览器」，以及 `tauri-exe/` 里内嵌 Node.js、开 WebView2 窗口的 Tauri 2 封装。玩家的仓库和预设存在浏览器存储里，位置由访问地址决定；换成 WebView2 窗口后存储位置必然变化，取代托盘启动器还要同时替换更新器、托盘和登录窗口。在没有设计好存档迁移之前，这个代价大于独立窗口带来的好处，所以正式发行不变，Tauri 2 封装只作为实验形态保留。

评估过 PyTauri，不采用：它用于以 Python 编写 Tauri 后端，而本项目运行时没有 Python 代码，后端是 Node 写的本机服务和 WASM 内核。采用它要么在发布包里再带一套 Python 运行时，要么用 Python 重写本机服务。

## Consequences

- Tauri 2 封装的应用标识、包名和端口使用固定值，不随版本变化；它们决定这份封装的存储位置。
- Tauri 2 封装不进入发版成品，发版核对只同步它的版本号。
- 要把 Tauri 2 封装变成正式发行形态，需要先立规格，覆盖构建脚本和从浏览器存储到 WebView2 的迁移，再更新本决策。
