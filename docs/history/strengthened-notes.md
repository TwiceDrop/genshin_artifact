# 角色加强与星扩散

瑞希按7.0加强内容核对，主要对照 [梦见月瑞希数据页](https://gi.gachabase.net/characters/10000109/yumemizuki-mizuki/release?lang=chs)。其他星扩散补全采用下方引用的公开正式版页面及2026-09-22保存的数据快照。

## 梦见月瑞希

原发布计算内核已经包含她的强化持续攻击、廓然梦生额外直接星扩散、一命直接星扩散，以及E和命座的星扩散加成。本次逐项测试这些数值，并补上实际使用时缺少的入口：

- 新增「梦见月瑞希·星扩散伤害」配装目标，可选廓然梦生直伤、一命直伤、风反应星扩散、冰反应星扩散。按真实期望伤害选择配装，计入精通、暴击与暴伤收益；旧「最大化元素精通」目标仍保留，适合纯精通辅助。
- 新选择瑞希时优先显示新的星扩散目标。旧保存方案保留原目标；旧方案需手动切换到新目标才会改为优化星扩散。
- 伤害表、详情弹窗和最优词条收益曲线区分「直接星扩散」和「反应星扩散·风／冰」。选中直接星扩散技能时，收益曲线优先使用该伤害。
- 角色设置中的强化开关沿用原内核行为，技能列表中的星扩散条目用于单独计算对应伤害；实际触发仍需满足游戏中的梦浮、辉映、命座与命中条件。

强化持续攻击和额外星扩散是两次不同的伤害，不将两者混成普通风伤。计算单次伤害或单种反应不等同于完整队伍时间轴DPS。已有原生武器覆盖率、队友BUFF和套装配置继续进入同一计算。

新目标已接入单人实际库存配装、多人库存配装、词条收益与伤害曲线。原内核的「理论最佳套装」入口忽略自定义目标，因此对该新目标明确提示暂不支持，防止返回按纯精通排出的结果；静态词条评分也不冒充星扩散伤害评分。

## 核查范围

七七「七宝奉真」补齐星扩散50%增伤，六命补齐其他前台角色直接星扩散的攻击力600%定额加值；不把定额加值算成角色面板攻击，也不加到普通反应星扩散。来源攻击力由队友BUFF配置提供。

桑多涅补齐星扩散的星耀祝礼、一命增伤、六命擢升，以及冷凝射线、棱晶弹、聚能光束、四命与六命附加段。技能使用1～15级的精确倍率，星扩散目标按每组候选的攻击、精通和双暴计算。六命附加段按单段展示；连发次数需由实际战斗条件决定。已有冰伤与星超导技能仍保留。

相关公开数据：[七七](https://gi.gachabase.net/characters/10000035/qiqi/release?lang=en)、[迪奥娜](https://gi.gachabase.net/characters/10000039/diona/release?lang=en)、[桑多涅](https://gi.gachabase.net/characters/10000133/sandrone/release?lang=en)。桑多涅参数快照与抽取结果保存在 `sources-strengthened` 和 `sandrone-stellar-skills.json`，便于后续版本对照。

七七六命直接加值的配装支持瑞希内置直接星扩散目标、桑多涅内置星扩散目标及薇斯纳原生目标；任意用户DSL暂不能自动改写，相关组合会明确提示。新星扩散目标使用实际库存配装，理论套装排行暂不支持。

本轮重点核对瑞希、七七、迪奥娜、桑多涅的星扩散加强。迪奥娜六命的星扩散40%增伤原本已经生效，不重复添加。

另外检查到八重神子、赛诺、莱欧斯利、北斗已有星超导相关技能或BUFF入口；温迪、可莉、阿贝多、莫娜、菲谢尔、砂糖、雷泽、杜林已有魔导相关配置或BUFF入口。入口存在不代表此次重新逐项验证了所有命座与时间轴，不将这部分概括成「全部角色已全面校准」。

## 测试

`npm run test:strengthened` 使用实际WASM核对瑞希技能等级1～15、命座增益、精通转换、双暴阈值、新目标四种模式及候选配装。结果见 [strengthened-tests.json](strengthened-tests.json)。

`npm run test:local` 包含伤害类型显示、曲线默认选择和Vue组件编译检查。武器覆盖率另由 `npm run test:limited71` 检查。

`npm run test:stellar-support` 检查七七、迪奥娜、桑多涅的队友增益和伤害／配装一致性；`node beta-tools/probe-sandrone-review.mjs` 另以独立公式检查桑多涅等级、命座与各个伤害乘区。
