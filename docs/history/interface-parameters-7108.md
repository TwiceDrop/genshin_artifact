# 7.1.08beta repair4：公共参数接口续查

日期：2026-09-30。继续修复单次伤害、单人配装和词条收益之间可复现的公共问题。保留 Debug 与原 README；仅更新本地网页版，没有 GitHub 发布或 Android 构建。测试使用五件合成圣遗物及额外合成候选，没有读取真实账号库存。

## 已修复

| 问题 | 实际影响 | 修复 |
| --- | --- | --- |
| 自定义敌人被配装／词条收益入口忽略 | 下方伤害使用当前敌人，而候选评分固定按 90 级、全抗 10%；混合元素目标可能选错圣遗物 | 旧核心桥接副本在构造敌人的两个入口写入本次等级及八种抗性；扩展 Rust 接口读取同样的敌人对象；每个候选都按实际敌人重新结算 |
| 禁用 BUFF 在部分旧接口仍有效 | 直接调用旧接口时，`lock:true` 的充能、武器、共鸣或套装 BUFF 仍可能改变面板；已禁用的星扩散倍率也会触发未适配拦截 | 在所有角色的公共输入入口统一过滤 `lock:true` / `active:false`，再进入校验与各内核。主页面此前已有解锁过滤，这次修复的是下层接口的不一致 |
| 零基准目标产生无穷大的百分比收益 | 例如精通为 0 时，以精通为目标的收益数组全是 `Infinity`，图表无法正确绘制 | 在返回图表前检查有限数值，明确提示基准值为零或收益无效；不把无穷大伪装成 0%。恒定零目标且没有增量时，继续返回空收益数组 |

敌人输入统一补齐缺省值，并在进入 WASM 前拒绝非整数／非正等级、NaN 或无穷大的抗性。允许负抗性与高抗性，保留原有分段公式。

没有用固定减防、全局伤害倍数或各角色独立补丁模拟敌人。已移除桑多涅／瑞希专用星扩散目标原有的抗性偏移补偿，防止真实敌人接入后重复计算。

## 数值证据

- 凯亚普通攻击、150 级敌人、物抗 60%：旧配装值 `901.6518113437501`；修复后配装与单次伤害均为 `346.0885740511364`。
- 默认敌人的 134 个角色默认目标：逐一与本轮改动前的配装结果、词条收益数组比较，保持一致。
- 八种伤害元素分别使用不同抗性，对照 A*、Naive 两种入口和单次伤害；附加减防 30%、穿防 25%、减抗 20%，以及二命雷电将军爆发穿防，检查敌人等级与已有防御效果的组合。
- 桑多涅／瑞希直接星扩散、薇斯纳原生目标和沃雅妮莎 DSL，核对真实敌人下的同一技能结果。
- 混合目标为“六次凯亚一段普通攻击 + 一次 E 融化”：物理杯／冰杯／攻击杯三种候选逐组独立算分，再与优化排序比较。默认敌人选择物理杯，分数 `9974.996848388251`；敌人改为 150 级、物抗 120%、冰抗 -40% 后选择冰杯，分数 `6356.989491791191`。固定当前装备的精通增加 23 收益从 `1.3726786537%` 变为 `2.7481175571%`，与两次实际伤害之比相符。
- 257 项 BUFF × 三种角色路径分别检查锁定与停用状态，不改变基准面板，也不触发已关闭效果的适配拦截。

## 仍保留的边界

本轮只修复单人候选评分的公共参数传递，没有把这些限制改成“全部兼容”：

- 原静态推荐中 121 条角色默认目标路径仍不支持；完整列表见 [上轮接口报告](interface-audit-7108.md#5-静态推荐未实现不支持名单)。实际配装与静态推荐是不同接口。
- 薇斯纳自定义 DSL、旧角色星扩散专属独立倍率、部分沃雅妮莎星扩散队友效果、旧角色漩流颂歌动态生命换算等既有限制仍保留。
- 三至四人反应星扩散排序继续标为近似；本轮没有新增或推断未知游戏公式。
- 多人联合优化不属于这次敌人参数修复的验收范围；不能从单人通过推断所有联合搜索都读取了当前敌人。
- 默认目录与代表组合通过不等于全部命座、触发状态、武器覆盖率和反应组合都已校准。
