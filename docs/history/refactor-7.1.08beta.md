# 7.1.08beta 本地重构版

本版在独立文件夹中重构角色 BUFF 层，服务于单次伤害计算和单人圣遗物配装优化。原 7.1.07 项目及其 README 保持原样；保留 Debug。未发布 GitHub，未制作 Android 包。

## 启动

当前 tray-repair1 网页包已附带 Node 运行时，解压后双击 `启动7.1.08beta.exe`。访问 `http://127.0.0.1:4184/#/calculate`。

本版使用 4184 端口，与旧版 4183 的浏览器数据空间分开。初次打开看不到旧版仓库属于正常现象；需要时在旧版导出，在新版手动导入。发行包未包含账户、仓库或用户调试样本。

## 已完成的重构

- 174 项角色 BUFF 由通用表达式执行器计算：属性、条件、表格倍率、上限、前后台和受益者身份均用数据描述。
- 11 项特殊队友 BUFF 抽出同样的数据公式，继续使用明确的伤害作用域适配层。
- 瑞希一命已纳入数据规则：普通扩散定额与反应星扩散风伤定额分别处理；精通输入为挂标记时的快照。
- 以上合计覆盖目录内 185 项角色 BUFF。角色自身技能、武器、套装和反应公式继续复用现有计算系统；本次并非将所有角色技能重写为新内核。
- 为发布内核新增属性写入桥接，分别覆盖带标签的单次计算和不带标签的优化计算。同一条数据规则可用于两条路径，百分比攻击/生命/防御仍通过原生依赖计算随候选圣遗物变化。

## 明确保留的兼容边界

旧内核仅接收已经确认槽位的属性。没有精确映射时整条 BUFF 使用原实现，防止部分写入或跨反应范围泄漏。奥黛塔部分星烁效果、迪奥娜星超导效果、瑞希战技及六命在旧内核上保留其原生范围。阿贝多来源防御为 0 的动态转换继续走原生依赖。

多人联合优化、完整循环 DPS 和理论排行不在本次重构范围。星扩散合成排序因资料冲突仍标为近似。旧角色新武器 1～89 级、白湖冬羽／朏魄含光部分覆盖、纺夜天镜／真语秘匣显式双状态重叠已补齐。沃雅妮莎普通水冰支援已改为元素属性，不再限于丝柯克默认优化目标；星扩散支援在其他旧角色上的配装入口仍有限制。歌声 Q 已按独立倍率接入单次计算和默认配装目标。更多明细见 `character-buff-migration-7108.md`。

网络资料、修补范围和仍需确认的具体问题见 `research-repairs-7108.md`。

## 以后如何新增 BUFF

统一入口为 `beta-data/character-effect-rules.mjs`，它组合经典、近期和月曜角色规则。规则由 `effect-rule-engine.mjs` 执行，编译成明确命名的属性。

1. 在界面目录填写名称和参数，运行 `node script/generate-buff-rule-schema.cjs` 同步参数校验。
2. 在相应规则簿增加 `R([E('属性名', 表达式)], {when, variables, assertions})`。使用 `rule-dsl.mjs` 中的表格、条件、上限等工具，避免新增角色专属执行函数。
3. 已支持的属性会自动进入扩展计算和旧内核桥接；新属性需补充精确的后端映射，新反应仍需新增并确认公式，不能仅添加名字。
4. 更新 `node script/report-effect-migration.mjs` 生成的清单，新增有明确预期值的定向验证。

例子：`R([E('ElementalMastery', mul(40, P('stacks', 1)))], {when: P('effect_active', true)})`。这是写法示例，不是任何角色的实装公式。

## 构建与核心来源

`npm ci` 后运行 `npm run build:local`。本工作目录的 node_modules 是指向现有依赖目录的本地联接；复制源码到别处需要自行安装依赖。

原始 WASM 文件不改动。新增桥接文件为 `mona_wasm/pkg/mona_effect_bridge.wasm`，重建脚本为 `script/build-effect-bridge.py --wabt <WABT 的 bin 目录>`，需要 Python 和 WABT。脚本校验原始 WASM 的 SHA-256 和两个写入点；内核更新后签名不符会停止，需重新确认映射，不能沿用旧槽位。

原始内核 SHA-256：`fa42077784f9556dd312743bc1327bd475970c53146e4867191f3cad63005b90`。
桥接内核 SHA-256：`a1844933b4d48bad98fba45901bb79325e8cee0a3b5ea4bed4661d220c7022ff`。
