# 限定四星、至冬纪行与锻造武器

7.1.02 加入3把限定四星，并补齐沃雅妮莎、薇斯纳所用扩展内核中的10把至冬武器。纪行和锻造武器此前已经存在于旧角色使用的发布内核；此次也核对了旧角色的特效，并修正两项配置问题。

| 类型 | 单手剑 | 双手剑 | 长柄 | 法器 | 弓 |
|---|---|---|---|---|---|
| 新限定四星 | 新枝 | — | — | 凝雪沉心 | 柔风游弦 |
| 至冬纪行 | 熔猎异端之刃 | 金律铸影 | 寒息 | 群王局戏 | 悬黎千钧 |
| 至冬锻造 | 引火之源 | 救赎之斩 | 戍望谣歌 | 寸心余响 | 霜雪誓约 |

## 配置方式

- 新枝：选择0～3层、普通或「辉映·星烁」模式、0～1覆盖率。普通模式每层提供攻击与精通；星烁模式改为攻击与星伤，不保留普通模式精通。
- 凝雪沉心：分别填写冰、雷角色数量，包含装备者，合计不超过4人。星烁模式替换普通模式的效果。
- 柔风游弦：20%/25%/30%/35%/40%充能常驻，覆盖率只影响触发后的队伍星伤。为其他角色提供效果时，在BUFF中添加「柔风游弦·蛇信的死毒」，填写来源精炼与覆盖率。同名效果取最高值，不叠加；队友不会得到装备者自身的充能加成。
- 金律铸影：当前普通乐章、复调开关和复调乐章分别设置。旧配置默认复调跟随当前乐章；也可以保留上一乐章的12秒复调。
- 悬黎千钧：仅填写其他队员，排除装备者；同元素与异元素合计最多3层，同元素优先。旧版2+2配置自动迁移为2+1。
- 熔猎异端之刃：沿用「效果比例」口径，0关闭、0.5为最低生效加成、1为最高生效加成，不是移动距离。
- 寒息、戍望谣歌：直接回能显示触发目标、数值与间隔，不转换为充能效率。寒息为其他队员回复能量，每16秒至多一次；戍望谣歌为装备者回复能量，每9秒至多一次。

各武器支持精炼1～5。13把武器均有覆盖率设置，填写0～1，1代表100%。新增的覆盖率在旧配置中默认100%，原有开关、层数、移动效果比例及「新枝」「柔风游弦」已保存的覆盖率都会保留。

| 武器 | 覆盖率控制 |
|---|---|
| 新枝 | 蓊郁层数对应特效的覆盖率 |
| 凝雪沉心、悬黎千钧 | 所填队伍构成对应被动的覆盖率，固定队伍通常保持100% |
| 柔风游弦 | 队伍星伤覆盖率；装备者常驻充能保持不变 |
| 熔猎异端之刃 | 攻击特效覆盖率，与移动效果强度相乘 |
| 引火之源、救赎之斩、寸心余响 | 普通元素反应效果与星烁反应效果的独立覆盖率 |
| 金律铸影 | 当前普通乐章与所选复调的独立覆盖率；保留跨乐章选择 |
| 寒息、戍望谣歌 | 攻击特效覆盖率和直接回能触发机会利用率，分别设置 |
| 群王局戏 | 同时作用于攻击与精通的同一特效覆盖率 |
| 霜雪誓约 | 精通特效覆盖率 |

覆盖率只折算武器特效，不缩放基础攻击、副词条或柔风游弦常驻充能。关闭特效开关时，相应特效仍为0，不因覆盖率为100%而重新启用。直接回能保留每次触发的数值，另显示「每个最短触发间隔的等效回能＝每次回能×触发机会利用率」；它不增加充能面板或伤害，也不会变更实际触发间隔。

覆盖率采用平均属性模型，不模拟每次命中与BUFF时间轴；先折算属性再计算伤害，因此不等同于开关状态伤害的时间加权平均。金律铸影只折算当前选择的普通乐章与复调，不自动混合三种轮转乐章。单人配装、伤害、词条收益与最优曲线使用同一配置。

## 数据及计算范围

已对照正式版 **7.1.0 D48145775 / R48145775**。来源URL、原始描述、65档精炼、13×96组等级/突破数据、原始曲线和页面SHA256保存在 [weapons-release-71.json](weapons-release-71.json)，页面快照保存在 `sources-release-71/`。13把武器的属性、突破、成长曲线和全部精炼参数与此前录入数值一致。

- [新枝](https://gi.gachabase.net/weapons/11437/new-bough/release?lang=chs)
- [凝雪沉心](https://gi.gachabase.net/weapons/14437/winters-heavy-heart/release?lang=chs)
- [柔风游弦](https://gi.gachabase.net/weapons/15437/breezeborne-refrain/release?lang=chs)
- [至冬武器目录](https://gi.gachabase.net/weapons/release?lang=chs)

扩展内核中的13把武器使用1～90级及六处突破前后的逐级数据：基础攻击按游戏显示整数，副词条保留四位小数。沃雅妮莎、薇斯纳可以装备其中对应类型的武器。

**旧角色的基础攻击仍沿用原发布内核的区间插值。** 为保留旧角色完整技能、命座及套装实现，3把新限定通过同基础攻击成长的已有武器接入旧内核，再替换精确副词条并注入特效。90级基础攻击与来源一致，部分非关键等级的基础攻击与逐级数据存在原内核插值误差；不要把这部分当作逐级精确结果。已有10把至冬武器也保留原发布内核的基础属性算法。

星伤在旧内核作用于星超导与星扩散；扩展内核保留此前薇斯纳星扩散模型及新角色计算限制。沃雅妮莎的星扩散、完整时间轴、多人联合配装等未校准范围没有因此解锁。薇斯纳仍不支持MONA-DSL；旧角色的3把新限定及队友BUFF已接入DSL入口。

## 复跑

```powershell
node beta-tools/extract-limited-weapons.cjs
node beta-tools/metadata-limited-71.cjs
npm run test:limited71
npm run build:beta-kernel
npm run build:local
```

提取脚本默认读取本地来源快照，传入 `--download` 才重新下载。专项检查使用实际双WASM，结果写入 `limited-71-tests.json`。重编扩展需要README中列出的Rust、MinGW和wasm-bindgen工具链。
