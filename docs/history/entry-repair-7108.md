# 7.1.08beta repair2：角色入口修复与手动面板整理

> 本文为 repair2 历史记录。独立星／月反应入口后来已移除；2026-10-01 用户又要求移除所有角色的主C手填面板。当前范围见 direct-reactions-only-7108.md。

## 修复内容

- 配装请求和单次面板请求的输入结构不同：配装候选圣遗物单独传给优化器，不等于当前穿戴。移除桑多涅原生目标进入搜索前的错误面板读取；原生星超导继续按候选装备计算自身天赋。
- 桑多涅合成星扩散目标与瑞希定额支持 DSL 编译所需的参考计算，补齐空装备及技能上下文。桑多涅的攻击转换由 DSL 读取每组候选的实际攻击，不固定为无装备面板。
- “单次伤害 · 主C手填面板”保留在计算器；“星／月反应计算 · 手动面板”移到侧栏独立页面。可以读取同一账号在计算器选择的角色面板和 BUFF；没有来源时仍可完全手填。上下文只存于内存，不自动上传。
- 修复旧角色添加沃雅妮莎队友 BUFF 后误删原生星／月反应结果的公共过滤路径。已接入的冰／水／风减抗按元素写入原生属性；未接入的星扩散专属定额、暴伤和擢升在显示时注明缺项，配装仍保留原有限制。
- 按用户要求，待校准分支保留内核已有预览值，在伤害行和明细标记“未校准·参考值”并说明缺项；当前技能未返回、与本次技能无关的反应不显示空行或警告；选择直接星／月反应技能时，只显示对应直伤结果，不把原生假设反应预览或普通伤害副本混入本次技能表。预览没有因此进入已校准列表或词条收益曲线。
- Debug 保留；README 未改；不发布 GitHub，不构建手机版。

## 验证范围

使用合成装备按界面目录批量检查，未将用户调试包或圣遗物保存进测试、源码或发布包：

- 134 个角色目录项（包括旅行者元素变体），144 个角色目标或通用回退目标，零命／满命、AStar／纯枚举，共 576 组入口检查。
- 同一目录的零命／满命共 4068 个单次技能配置，检查计算完成及结果有限。
- 132 个原生角色的 2002 个技能配置，逐项对照沃雅妮莎支持适配与原生元素减抗输入，确保既有反应结果不会被公共过滤误删。
- 两组不同候选装备的桑多涅星扩散优化结果，与单次伤害独立评分对比一致。
- 用户提供的桑多涅调试输入在内存回放，返回 100 组有效配装。

这些检查覆盖入口兼容及上述候选动态计算，不代表逐项审定所有角色、武器、圣遗物、BUFF 的所有组合和游戏公式。

## 保留限制

- 旧角色装备“漩流颂歌”，蜜酿层数大于零且前台生效时，目前无法把自动读取生命的转攻击效果逐套接入旧内核优化。若来源生命留为 0，配装明确报出原因；可以手动指定已确认的固定来源生命，或关闭蜜酿层数。固定来源生命不会随候选装备改变，不应把这种模式当作自动生命换算。
- 原有未适配与近似标记保留，包括多人星扩散的排序近似及尚未支持的跨内核特殊效果。本次没有通过删除限制扩大适配声明。

解压新版网页包，关闭旧版本地服务，运行“启动7.1.08beta.bat”。保持原来的浏览器与访问地址可继续读取本地保存数据；必要时 Ctrl+F5 刷新。

构建后真实计算线程回放通过：返回 100 组有限结果。
