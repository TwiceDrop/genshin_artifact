# 用户提供的直伤型星超导公式

来源：本任务用户于2026-09-26提供截图 user-direct-stellarconduct.png。截图中的站点标记不是本地已访问的网页链接，本说明不把它当作已独立核验的外部来源。

可见公式与文字合并记录为：

D = [ATK × M × K × (1 + Bbase) × (1 + 6EM/(EM+2000) + Bstellar) + Qextra] × C × R × (1 + E)

截图右侧公式被横向截断，最后(1+E)依据下方“E：擢升区，是独立乘区”说明补全，属于对用户材料的解释。

ATK为桑多涅最终攻击，M为该次星超导专用倍率，K为极星辉域系数，Bbase为基础提升，Bstellar为星超导/星烁增伤，Qextra为额外定额。期望C=1+暴击率×暴击伤害；R取对应元素抗性；普通冰伤增伤和敌方防御不参与。

该图限定直伤型星超导，未提供触发反应型多人合成、K层数表、独立伤害倍率是否参与、来源归属或各角色技能参数。不得据此将全部星/月反应标为已校准。原发布内核已有桑多涅直伤星超导入口，需要结合原实现核对，不删除现有反应限制冒充修复。
