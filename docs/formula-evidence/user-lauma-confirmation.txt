## 苍色祷歌不是“反应增伤%”，而是定额伤害加值

这是实现时最重要的地方。

假设：

```text
EM_Lauma = 菈乌玛元素精通
```

有一层苍色祷歌被消费时：

### 普通绽放系

\[
F_{\rm PaleHymn}
=
EM_{\rm Lauma}
\times
Q_{\rm Bloom}(Lv)
\]

### 月绽放

\[
F_{\rm PaleHymn}
=
EM_{\rm Lauma}
\times
Q_{\rm LunarBloom}(Lv)
\]

这个值属于**反应定额伤害加值**，不是：

```text
ReactionDamageBonus += 500%
```

例如 Q10、1000 精通：

- 绽放/超绽放/烈绽放：额外定额值 = `1000 × 5.0 = 5000`
- 月绽放：额外定额值 = `1000 × 4.0 = 4000`

公开机制说明也明确将它描述为在原本反应计算后加入的额外基础数值，再进入后续抗性等结算。:chatgpt-content-reference{index="5"}

因此普通绽放类可抽象成：

\[
D=
\Big[
D_{\rm reaction,preRes}
+
F_{\rm PaleHymn}
\Big]
\times R
\times C_{\rm if\ allowed}
\]

而不是：

\[
D_{\rm reaction}\times
(1+Q\times EM)
\]

# 苍色祷歌层数规则

Q 施放立即获得：

\[
18\text{ 层}
\]

若施放 Q 时已经有「月咏」，或 Q 后 15 秒内获得月咏，则**一次性**消耗全部月咏：

\[
+6\times N_{\rm MoonSong}
\]

月咏最多 3 层，所以普通情况下：

\[
18+6\times3=36
\]

即最多 36 层。这个“月咏→苍色祷歌”转换每次 Q 只能触发一次。:chatgpt-content-reference{index="6"}

每层持续时间单独计算；当一段符合条件的反应伤害同时命中多个敌人时，会按命中的敌人数消费多层。:chatgpt-content-reference{index="7"}

所以不要简单写：

```text
onReactionDamage:
    stacks -= 1
```

更接近：

```text
stacksConsumed = eligibleTargetsHit
```

当然要受当前剩余层数限制。

# C2 的正确合成

C2 有**两个完全不同的效果**。

### ① 苍色祷歌定额值额外增加

C2：

- 绽放/超绽放/烈绽放：再加 `500% × 菈乌玛精通`
- 月绽放：再加 `400% × 菈乌玛精通` :chatgpt-content-reference{index="8"}


所以应该直接加到 Q 的定额倍率：

\[
Q_{\rm Bloom,eff}
=
Q_{\rm Bloom}(Lv)+5.0
\]

\[
Q_{\rm LB,eff}
=
Q_{\rm LB}(Lv)+4.0
\]

例如 **Q10 + C2**：

\[
F_{\rm Bloom}=EM_{\rm Lauma}\times(5+5)
=10EM_{\rm Lauma}
\]

\[
F_{\rm LB}=EM_{\rm Lauma}\times(4+4)
=8EM_{\rm Lauma}
\]

也就是说 C2 **不是把 Q 原来的效果 ×2**；只是 Q10 恰好因为基础值就是 500%/400%，所以数值看起来翻倍。

如果 Q13：

```text
Bloom:      5.902 + 5.000 = 10.902 × EM
LunarBloom: 4.723 + 4.000 =  8.723 × EM
```

因此代码应是：

```text
flatCoef =
    burstTalentCoef[level]
    + (c2 ? c2FlatCoef : 0)
```

而不是：

```text
flatCoef = burstTalentCoef[level] * 2
```

---

### ② C2 满辉：月绽放伤害 +40%

这是另一条：

```text
if C2 && Moonsign == AscendantGleam:
    LunarBloomDamageBonus += 0.40
```

官方文本语义是“月绽放反应伤害提升 40%”，KQM也把它解释为月绽放的普通 DMG Bonus。:chatgpt-content-reference{index="9"}

它**不是苍色祷歌定额加值的一部分**。

所以建议不要把两者都塞进 `LaumaBurst` 一个数字。

# C6 满辉则又是第三个乘区

C6 满辉文本是：

> 月绽放反应伤害**擢升 25%**。:chatgpt-content-reference{index="10"}

这里用了专门的“擢升”，KQM明确说明这是**与普通 Lunar-Bloom DMG Bonus 分离的新乘区**。:chatgpt-content-reference{index="11"}

所以：

```text
if C6 && AscendantGleam:
    LunarBloomElevation *= 1.25
```

而不是：

```text
LunarBloomDamageBonus += 0.25
```

于是 C2+C6+满辉同时存在时，结构应是：

\[
\boxed{
D_{\rm LB}
=
D_{\rm beforeElevation}
\times(1+0.40+\text{其他普通月绽放增伤})
\times1.25
}
\]

不是：

\[
D\times(1+0.40+0.25)
\]

这点和你前面在拆“普通独立倍率 / 擢升”是同一个问题。
