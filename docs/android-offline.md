# 安卓本地版

## 1.0.1 全面屏修复

状态栏、显示挖孔、导航手势区和软键盘由安卓原生容器统一避让；不再给 WebView 本身加 padding，也不叠加框架的 CSS 安全区处理。竖屏、横屏切换和键盘收起都会重新计算可用区域。计算器采用页面滚动，修复分区标签重复下移、遮挡角色入口，以及立绘造成的横向溢出；手机首页标题缩小。

此版本与 1.0.0 使用相同包名、相同签名，可直接覆盖安装，保留已有数据。原生布局测试覆盖手势导航、三键导航、横屏挖孔、键盘出现与收起，并检查实际 Activity 的 WebView 边界。

安装包：`releases/mona-offline-android.apk`，Android 7.0 及以上。保持 Android System WebView 为较新版本。

将 APK 发送到手机，在文件管理器中打开安装。更新时直接覆盖安装，保留应用数据；卸载或清除应用数据会删除本机角色、装备、历史与 Cookie。

## 电脑与手机互传

1. 电脑双击项目根目录的“启动莫娜.bat”，进入“UID 数据 / 手机互传”。
2. 在“已保存的角色”中选择要导出的 UID，点击“导出此 UID 到手机 / 电脑”。
3. 若手机需要从整个仓库寻找最佳装备，勾选“附带当前仓库全部圣遗物”；未勾选时只携带该 UID 角色/预设/历史所引用且仍在仓库中的装备。
4. 把生成的 JSON 文件发送到手机，打开 App 底部“UID 数据”，点击“导入 UID 数据包 / 角色快照”。
5. 点击导入的角色进入计算器。手机也可以导出同样格式的文件，再在电脑导入。

文件包含所选 UID 的角色养成、武器、游戏内装备快照、计算预设及配装对比历史。其他 UID 不会被删除；同一 UID/角色的预设在再次导入时更新。装备通过内容指纹复用并重映射编号，重复导入不会不断新增同一批装备。仓库里原本存在的多件相同词条装备会保留其数量。

Cookie 不包含在互传文件中。手机端可独立扫码或手动录入 Cookie，使用 Android Keystore 加密存储；接口失败、关闭 App 不自动删除，只有手动“删除 Cookie”才移除对应账号。登录二维码可保存为图片，再从米游社扫一扫识别。

## 本机运行范围

- 角色/武器/圣遗物资料、图片、WASM 计算内核、评分权重、图表与编辑器资源随 APK 安装。
- 伤害与套装优化、多人优化、圣遗物评分排名、毕业度、0～20 词条收益、配装对比/历史及面板增减均在手机本机运行。
- 底部导航提供计算、仓库、UID 数据和全部功能；计算器分成角色配置、圣遗物与伤害、面板与曲线。弹窗与触控输入适配窄屏。
- 米游社同步需要联网，由手机直接请求米游社，无需电脑或自建服务器。接口可能要求账号验证；失败时保留已有数据和 Cookie。
- 米游社仅提供角色已装备圣遗物。背包 OCR/YAS 扫描仍在电脑完成，扫描结果/完整仓库可通过 JSON 导入手机。
- 安卓端的圣遗物分享导出为本地 JSON，不创建依赖在线服务器的分享链接。外部帮助和源码链接需要联网。
- 莫娜数据库在安卓端展示本机已保存预设的武器、套装、主副词条统计，并明确标注本机样本来源；不会联网读取社区统计。

## 构建与更新

运行根目录“打包安卓.bat”，或 `npm run android:apk`。需要 Node.js 22+、Java 21、Android SDK 36；脚本优先使用本机 Android Studio JBR 和默认 SDK 目录，也支持 JAVA_HOME / ANDROID_HOME。

脚本执行移动端构建、Capacitor 资源同步与 Gradle release 打包，并生成 SHA-256 校验文件。手机使用 APK 内置资源，没有远程 server.url。桌面构建仍使用 `npm run build:local`。

**保留 `.local-data/android-signing.jks` 和 `.local-data/android-signing.json`。** 后续覆盖升级必须使用同一签名；这两个本机文件不进入 Git，不要随源码公开。版本发布时递增 `android/app/build.gradle` 中的 versionCode。
