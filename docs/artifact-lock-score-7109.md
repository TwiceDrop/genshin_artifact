## 已确认原因

计算器的“锁定全部”调用 `handleLockAll()`，将五件圣遗物的 `omit` 设为 `true`。这个标记用于将锁定件排除出后续配装候选。

`src/composables/artifact.ts` 的 `artifactWasmFormat` 同时用 `a && !a.omit` 过滤当前装备。因此界面仍显示原来的五件，但传给属性、伤害和词条收益内核的装备在锁定后变成零件。评分读取的是仍显示的五件圣遗物和已丢失装备属性的角色面板，依赖精通、生命等面板条件的评分规则可能切换。

该问题存在于共享装备转换入口；单件锁定也会移除对应件的计算属性。直接使用固定评分权重的角色可能总分不变，但不能据此认定当前装备计算正常。

## 最小修复

仅将当前装备转换条件改为 `if (a)`，保留已装备的锁定件。没有修改喵喵公式、角色权重、锁定状态或配装候选筛选，也没有冻结评分。

`getAllArtifactsFiltered()` 继续排除 `omit` 为真的候选件。实际更换装备或修改词条后，面板和条件评分仍重新计算。
