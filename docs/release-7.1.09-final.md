# 莫娜占卜铺 7.1.09

发布 Windows 64 位 EXE 安装包、附带 Node.js 的 ZIP 便携包及 Android APK。Windows ZIP 解压后运行 `启动7.1.09.exe`；Android 沿用原包名和升级签名。保留账号、UID、圣遗物仓库、配装预设和 Debug。

## 新增与改进

1. 支持 GOODScanner 的 GOOD v3 和 YAS 的 GOOD v1 圣遗物文件，通过原圣遗物导入入口使用；补全主词条成长值、百分比单位、套装名称和装备归属。导出工具页已加入 GOODScanner 项目链接。
2. 接入软件内更新：自动检查新版本、查看更新日志、检测下载线路、选择直连或第三方线路、后台下载进度与取消。Windows 衔接安装版／便携版更新，Android 进入系统 APK 安装与授权流程。
3. 预设菜单增加元素筛选和最近更新／元素排序；保存预设时记录更新时间，保留保存、另存与应用操作。
4. 在原“选择 BUFF”弹窗的“角色引发的 BUFF”页签增加元素筛选，可与搜索组合；保留 UID、角色选择和 BUFF 参数。
5. 圣遗物锁定按钮使用蓝底白色闭锁图标，解锁后恢复默认开锁状态。仓库和计算器共用，只改变锁定控件的填充。

## BUG 修复

6. 修复计算器“锁定全部”后当前装备被移出计算、导致面板与圣遗物评分变化的问题。锁定件仍参与当前装备计算，后续配装候选继续排除锁定件。
7. 修复 Android 更新下载把正常整数 APK 大小读成 0、完整下载仍被判不完整的问题。原生读取正确的大小并共用于持久化和进度，保留完整性判断。
8. 修复 Windows 便携更新因默认安装目录末尾分隔符而拒绝程序目录的问题，更新目录比较保持正确边界。
9. 修复三副词条升级后新增第四副词条时原 ID、锁定与保存配装引用丢失的问题。可双向唯一确定的升级保留原 ID 和锁定，歧义配对不猜测。
10. 修复角色具名评分流派漏掉专武、绝缘四件套及西风系列全局权重修正的问题；心海西风秘典、琴绿剑和绫华精通流等对应权重正确生效。
11. 修复玛薇卡评分绕过已有角色规则的问题。精通低于 50 时使用纯火／超载规则，其他情况保留上游精通权重 85；覆盖精通 0 与 40–49 的分支。
12. 修复绝缘评分充能权重错误限为 75 的问题，改为原权重 +75 后按当前最高缩放权重截取，原充能权重为 0 时也能生效。
13. 对齐喵喵评分返回标题的标签拼接和最终算分运算顺序，不修改角色权重来源或固定评分模板。
14. 修复部分装备导入时五部位收藏夹槽位挤占的问题，未装备部位保持空槽；阻止缺少圣遗物类别或空文件进入删除仓库／清空导入收藏夹的路径。
15. 保留软件内原有锁定含义。GOOD 的游戏内 lock 不自动排除莫娜配装候选，重复导入和确认升级继续保留原软件锁定。

7.1.08 已发布的 44 项修复继续保留，完整历史见 [7.1.08 更新说明](https://github.com/TwiceDrop/genshin_artifact/releases/tag/v7.1.08)。库存原生静态推荐权重按用户要求继续暂缓；角色喵喵评分与实际伤害优化不替代库存推荐。
