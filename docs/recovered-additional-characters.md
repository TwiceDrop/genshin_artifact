# 追加恢复的角色 BUFF 规则

> 更新纠正：IllugaQ现已按显式单次状态接入，月结晶定额只给直伤，不给月笼谐奏。原记录从公用属性推断反应型也适用不成立。见 [本批说明和网页证据](lunar-character-adapters.md)。其余历史状态以最新覆盖清单为准。


本次在 `beta-data/shared-buff-rules.mjs` 追加 MonaMagusGlow、PruneTalent2、IllugaP2 三项规则。它们生成已有原生属性，不改动已发布 WASM，不删除星／月反应校准拦截。IfaTalent2、IllugaQ 的数值规则已经静态恢复，但本次没有新增配方。

## 输入与触发边界

- 配置字段、默认值、范围及中文名称来自 `src/assets/_gen_buff.js` 和 `src/i18n/generated/zh-cn.json`。
- 手动添加 BUFF 表示本次命中满足来源解锁、施放、触发、附近范围和持续时间等前置条件；当前规则不模拟战斗时间轴、逐次消耗或自动推断来源命座。
- 配方产生的是属性增量。百分数以小数存储，固定面板以实际值存储。注册表会校验有限数值、范围和布尔类型。
- 独立月曜手填面板采用填写者提供的完整反应面板，未自动读取这些 BUFF。读取普通面板后，应确认反应专属增益及双暴；不能因配方存在就认为手填反应、实际角色技能与优化目标已经全部自动互通。

## 本次已接入

### 莫娜：水星天的辉光（MonaMagusGlow）

`stack` 是浮点参数，默认 3，范围 0～3，保持原内核不取整的语义。

`EnhanceVaporize = 0.05 × stack`

它加入蒸发的反应提升区，与元素精通提供的反应增益相加，不是通用增伤或独立乘区。默认 3 层为 0.15。复杂伤害分析与简单伤害／配装路径均读取同一属性：`complicated_damage_builder.rs` 的 `get_enhance_vaporize_composition`，以及 `simple_damage_builder.rs` 的蒸发分支。

中文描述限定莫娜普攻／重击取得辉光后，由队伍中自己的其他角色触发蒸发并消耗所有层数；本次配方明确排除 `input.character.name === 'Mona'` 的受益者。配置代表所计算命中可消耗的层数，不代表连续多次蒸发自动维持满层。

原发布代码的属性写入函数只接受来源配置和属性图，没有执行受益者身份判断；“其他角色”排除来自现有界面效果描述。加入此判断是保留效果适用范围，而不是从原函数推断出不存在的运行时角色检查。

### 布伦妮：振铃同心（PruneTalent2）

`prune_atk` 为浮点，默认 4000，范围 0～4000；`rate` 为浮点，默认 1，范围 0～1。

`BonusBase = min(max(prune_atk − 2000, 0) × 0.00025, 0.5) × rate`

原发布内核实际写入普通 `BonusBase`，不是独立倍率。默认配置为 0.5；2000 攻击及以下为 0。无需新建属性，也不向 `IndependentBaseMultiplier` 或 `StellarSwirlIndependentBaseMultiplier` 写值。

普通伤害通过 `AttributeCommon::get_bonus` 和复杂伤害构造器的 `get_bonus_composition` 消费此增量。直接星扩散／月曜公式不因这个普通增伤属性而额外获得倍率。该配方没有额外添加“仅魔导受益者”等界面不存在的条件；不要将布伦妮天赋1的资格限制混入天赋2。

### 叶洛亚：铸灯者的盟约（IllugaP2）

`is_c6` 与 `full_moon` 均为布尔，默认 false。中文描述为施放战技或爆发后，提高队伍角色岩元素伤害双暴，满辉时另给元素精通。

| 条件 | CriticalGeo | CriticalDamageGeo | ElementalMastery |
|---|---:|---:|---:|
| 非六命、非满辉 | 0.05 | 0.10 | 0 |
| 非六命、满辉 | 0.05 | 0.10 | 50 |
| 六命、非满辉 | 0.10 | 0.30 | 0 |
| 六命、满辉 | 0.10 | 0.30 | 80 |

精通是普通 `ElementalMastery`，不是 `ElementalMasteryExtra`。双暴严格写入岩元素属性，不替换成通用双暴或星反应双暴。现有普通岩伤的简单／复杂伤害路径均有对应消费者。

原发布直伤月结晶路径会合并岩元素及专属反应双暴；新建的独立月曜手填面板不自动做这种合并，使用者应填写最终反应双暴，避免遗漏或重复计入。恢复 P2 属性规则不解除新角色月结晶路径的校准限制。

## 数值已恢复，本次保留未适配

### 伊法：救援要义（IfaTalent2）

`rescue_essentials` 为浮点，默认 0，范围 0～200，不取整。原 BUFF 专用函数仅在数值大于 0 时写入：

- `EnhanceSwirlBase = 0.015 × rescue_essentials`
- `EnhanceElectroCharged = 0.015 × rescue_essentials`
- `EnhanceMoonelectro = 0.002 × rescue_essentials`

200 点时分别为 3、3、0.4。伊法自身角色被动函数另有 80／100 精通开关，这些不是本 BUFF 的字段，不能混入队友规则。

普通扩散、感电已有属性消费者。复杂伤害构造器的月感电与直伤月感电也实际读取 `EnhanceMoonelectro`，将其加入 `1 + 6EM/(EM+2000) + 反应增伤`。但当前新角色相关结果仍受反应校准拦截保护。`IneffaDefault` 的旧手写目标函数又将反应型月感电的精通和增伤分乘，与复杂计算器口径不一致，因此不能将“属性能写入”当作月感电计算与配装已统一。

本次不新增仅有普通两项的部分配方，不把完整三项规则的恢复计为解除月感电限制。

### 叶洛亚：魇夜的莺歌（IllugaQ）

现有 UI 输入：`em` 浮点默认 2000，范围 0～20000；`skill_level` 整数默认 10，范围 1～15；`team_hydro_geo_count` 整数默认 1，范围 0～3。原角色配置说明人数为其他水／岩角色，不含叶洛亚自己；BUFF 字段标题较简略，未来接入应补清楚这一点。

原内核的两条输出均按来源精通缩放：

`普通岩伤定额 = 来源EM × (A[技能等级−1] + 岩伤人数系数)`

`月结晶定额 = 来源EM × (B[技能等级−1] + 月结晶人数系数)`

- A = `[0.336, 0.3612, 0.3864, 0.42, 0.4452, 0.4704, 0.504, 0.5376, 0.5712, 0.6048, 0.6384, 0.672, 0.714, 0.756, 0.798]`
- B = `[2.2592, 2.4286, 2.5981, 2.824, 2.9934, 3.1629, 3.3888, 3.6147, 3.8406, 4.0666, 4.2925, 4.5184, 4.8008, 5.0832, 5.3656]`
- 其他水／岩人数 0／1／2／3 时，岩伤人数系数为 `[0, 0.07, 0.14, 0.24]`，月结晶人数系数为 `[0, 0.48, 0.96, 1.6]`。
- Q 本身没有额外六命系数。

普通岩伤写入原索引202（`ExtraDmgGeo`），月结晶写入原索引113。月结晶定额在本体增幅后添加，并接受暴击、抗性及擢升；原属性存在多个消费者，不足以证明叶洛亚Q也作用于反应型；实际只适用直伤。上述为原始恢复记录；后续批次已添加 ExtraDmgDirectMoonCrystallize 和显式消费者，普通岩伤也已接入。本次单击可用层数由调用者声明，仍没有自动状态轴和该角色技能优化。

原反应预览还存在 0.96 的旧归一化路径，不能原样覆盖本次用户指定的 1.6 与 60%／30%／5%／5% 合成公式。
