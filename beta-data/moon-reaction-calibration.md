# 月反应核查范围（7.1.05）

本仓库固定角色数据为 `7.1.0 D48145775`，见 `characters-release-71.json`。沃雅妮莎的技能、天赋和命座描述涉及水/冰伤害、冻结和星扩散，没有由她的技能直接造成月绽放、月感电或月结晶伤害的说明。[官方 7.1 更新公告](https://ys.mihoyo.com/main/news/detail/166392)也将她定位为冻结、星扩散队伍中的治疗与辅助。因此，元素为水只说明她可能在特定队伍中提供水附着，不能据此把普通水伤改为月反应直伤。

- [TapTap 菈乌玛分析原文](https://www.taptap.cn/moment/715110840100981265)给出直伤月绽放的基础、额外提升、暴击和抗性结算顺序，并明确其伤害由特定角色消耗草露产生。该式可用来研究菈乌玛，不能凭类比加到沃雅妮莎技能。
- 用户提供的 [360 游戏转载](https://v5.360game.360.cn/gknow_article/content?id=688b4b0fbccad6b3543f084b)可追溯到[幕陵的实测文章](https://www.gamersky.com/handbook/202507/1970668.shtml)：月感电雷击只计入目标身上仍残留的水、雷附着来源；先分别结算伤害，再按本次伤害从高到低乘 `1, 1/2, 1/12, 1/12`。原文样例 `7096 + 6264/2 + 4620/12 = 10613` 已在 `tests/moon-electro-team.test.mjs` 独立校验。暴击可能改变排序，因此 `moon-electro-team.mjs` 对每个暴击状态重新排序，再求期望。
- [羽化哲公式页](https://yuhuazhe.cn/gongshi.html)页首声明公式是网络收集且有未改错误，月结晶段落还注明其公式尚未修正。它可作研究线索，不能单独证明沃雅妮莎月结晶技能或解除公式保护。

`moon-electro-team.mjs` 只处理已明确给定月反应转换、雷暴云、目标水雷共存，以及 2～4 名仍有附着的来源时的**单次雷击合成**。它不推断触发时机、附着所有权、各人的基础贡献，也不计算轮转。现有界面/优化输入没有这些状态，因此沃雅妮莎的月反应结果仍标记为待校准或条件未满足，不把单人贡献误报为队伍总伤。歌声 Q 的 86.4% 乘区与本次核查无关，维持原保护。
